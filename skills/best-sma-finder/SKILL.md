# 无忧均线 · 自动识别最优移动平均线

> 移动平均线（Moving Average）由美国投资大师 **约瑟夫·格兰维尔（Joseph Granville）** 在其1960年出版的《格兰维尔股票市场获利新策略》中系统提出，是技术分析领域最基础、应用最广的分析工具之一。
>
> 格兰维尔的核心理念：**价格围绕均线波动，均线代表市场参与者的平均成本。** 当价格偏离均线过远时会回归，当价格穿越均线时趋势可能转变。

本技能不预设任何均线长度，而是用数据说话——暴力枚举、多维评估、自动推荐。

---

## 它解决什么问题

大多数技术分析工具把均线固定为 5/10/20/60 日，但**不同标的的自然节奏完全不同**：

| 标的类型 | 适合周期 | 说明 |
|---------|---------|------|
| 大盘指数（上证/沪深300） | 月线/周线优先 | 趋势稳定，噪音少 |
| 价值大票（茅台/招商银行） | 周线为主 | 日线噪音太多 |
| 成长科技（东方财富/宁德时代） | 日线更敏感 | 趋势变化快 |

本技能**三周期同时扫描**，也支持**单周期深度分析**，用数据告诉你哪条均线最适合当前标的。

## 核心功能

### 1️⃣ 最优单均线（`--method single` / `--method both`）

价格上穿SMA买入，下穿卖出，Long Only不做空。  
**双维度推荐**——同时输出两套结果：

| 维度 | 含义 | 适合谁 |
|------|------|--------|
| 📈 **按盈亏比(PF)最优** | 赚的总金额 ÷ 亏的总金额，越高说明"赚大亏小" | 追求单笔大利润的人 |
| 🎯 **按胜率最优** | 赚钱交易次数 ÷ 总交易次数，越高说明"买的准" | 追求高成功率的人 |

### 2️⃣ 双均线交叉（`--method cross` / `--method both`）

短期均线（fast）上穿长期均线（slow）→ **金叉买入**  
短期均线下穿长期均线 → **死叉卖出**

对所有可能的(fast, slow)组合暴力枚举，找出PF和胜率均最优的双均线对。

### 3️⃣ 无忧线 · 回踩买入永久持有（`--method eternal`）

**划时代的概念——你还在猜底，我们直接算底。**

原理：统计历史上每当价格回踩某条均线后买入并永久持有，最终是赚是亏。

**输出指标：**
| 指标 | 含义 |
|------|------|
| ✅ 胜率 | 历史上回踩这条均线买入后最终赚钱的概率 |
| 💰 平均收益 | 历史平均涨幅 |
| ⏱ 最大被套时长 | 买入后最深浮亏持续了多久（最坏情况的时间成本） |
| 📉 最大浮亏 | 买入后曾经最多亏了多少（心理承受极限） |
| 🔒 无忧区间 | 连续N条均线都是100%胜率，在其中随便选 |

> ⚠️ **适用范围**：无忧线仅适用于大盘蓝筹和宽基指数，不适合小盘股（有退市风险）。

### 4️⃣ 多周期对比（`--compare`）

日线/周线/月线同时跑一遍，按PF排序，自动推荐最稳健的周期+均线组合。

### 5️⃣ KNN 增强模式（`--mode knn`）

暴力枚举找"全历史最强"，KNN找"当下最合适"：
- 提取当前市场特征（波动率/动量/趋势强度）
- 在历史中找K个最相似窗口
- 看哪个候选均线局部表现最好

## 实战案例 · 上证指数（000001）

以下是对上证指数（1990年至今）的全维度分析结果：

### 最优单均线

| 维度 | 推荐 | 数据 |
|------|------|------|
| 🎯 **按胜率** | 日线 SMA 30 | 胜率 **28.8%**，PF **1.54** |
| 📈 **按盈亏比** | 同上（日线仅此一条有效） | 52次交易，信号稳定 |

> 为什么胜率只有28.8%就算有效？因为PF（盈亏比）> 1，说明赚的时候赚得多、亏的时候亏得少。**这就是趋势跟踪的精髓：宁可错9次，对1次就能全赚回来。**

### 无忧线深度分析

**核心结论：上证指数的终极无忧线是日均线 SMA 275（等价周线 SMA 55）。** 历史上回踩买入永久持有，从未出现最终亏损的情况。

#### 日线无忧线（SMA 275 ≈ 13个月）

| 指标 | 值 |
|------|------|
| 历史回踩次数 | **81次** |
| 胜率 | **100% ✅** |
| 平均收益 | **+19.4%** |
| 最大被套时长 |约 3.6 年 |
| 平均被套时长 |约 1.3 年 |
| 最大浮亏 | 约 32.3% |
| 平均浮亏 | 约 17.1% |
| 无忧区间 | **SMA 275 ~ 320** 全部100%胜率 |

#### 周线无忧线（SMA 45 ≈ 10个月）

| 指标 | 值 |
|------|------|
| 历史回踩次数 | **74次** |
| 胜率 | **100% ✅** |
| 平均收益 | **+125.4%** |
| 最大被套时长 | 约 7.6 年 |
| 平均被套时长 | 约 2.4 年 |
| 最大浮亏 | 约 73.1% |
| 平均浮亏 | 约 21.0% |
| 无忧区间 | **SMA 45 ~ 200** 全部100%胜率 |

#### 终极验证：月线 SMA 200（16.7年）

| 指标 | 值 |
|------|------|
| 历史回踩次数 | **7次** |
| 胜率 | **100% ✅** |
| 最大被套时长 | 约 **1.2 年** 🤯 |
| 最大浮亏 | 约 **12.8%** 🤯 |
| 平均浮亏 | 约 **5.1%** |

> 这就是格兰维尔理论的终极体现——**200月均线≈社会平均成本线**，熊市恐慌性杀跌到这个位置，历史上极少有效跌破，回踩后迅速反弹。

### 均线越长 → 回踩越少 → 被套越短 → 浮亏越浅

| 均线 | 等价年数 | 回踩次数 | 最大被套 | 最大浮亏 |
|------|---------|:-------:|:--------:|:--------:|
| SMA 50 | 4.2年 | 17次 | 4.1年 | 39.1% |
| SMA 100 | 8.3年 | 14次 | 4.3年 | 24.1% |
| SMA 150 | 12.5年 | 14次 | 3.8年 | 18.8% |
| **SMA 200** | **16.7年** | **7次** | **1.2年** | **12.8%** ✅ |

## 小白术语解释

| 术语 | 通俗解释 |
|------|---------|
| **SMA** | 简单移动平均线。把过去N天的收盘价加起来÷N，就是N日均线。例如5日均线=过去5天平均价 |
| **PF（盈亏比）** | Profit Factor = 赚的总金额 ÷ 亏的总金额。PF=2意味着赚1块的同时只亏5毛，净赚5毛。PF>1说明策略整体赚钱 |
| **胜率** | 赚钱交易次数 ÷ 总交易次数。胜率60%意味着每10笔交易6笔赚钱 |
| **无忧线** | 历史上每次价格跌到这条均线附近买入并死拿不卖，最终都赚钱——从未失手 |
| **无忧区间** | 连续多条均线都是100%胜率，随便选一条都行。相当于安全垫加厚 |
| **被套时长** | 买入后价格一直低于买入价的最长持续时间。被套1年意味着你要扛一年的浮亏等反弹 |
| **浮亏** | 买入后股价下跌，账面上亏的钱。浮亏30%意味着100万本金曾跌到只剩70万 |
| **金叉** | 短期均线上穿长期均线，通常被视为买入信号 |
| **死叉** | 短期均线下穿长期均线，通常被视为卖出信号 |
| **Long Only** | 只做多不做空。均线上方买入、下方卖出空仓，不靠下跌赚钱 |

## 使用方式

```bash
# ★ 推荐：多周期全维度分析（单均线 + 双均线交叉）
python3 scripts/find_best_sma.py --symbol sh000001 --compare --method both

# 无忧线分析（回踩买入永久持有）
python3 scripts/find_best_sma.py --symbol sh000001 --method eternal --bars 1500 --end 500 --min_trades 10

# 单周期暴力枚举单均线
python3 scripts/find_best_sma.py --symbol 600519

# 双均线交叉
python3 scripts/find_best_sma.py --symbol 300059 --method cross

# KNN增强模式
python3 scripts/find_best_sma.py --symbol 600519 --mode knn

# 港股分析（5位代码自动识别）
python3 scripts/find_best_sma.py --symbol 00700

# ETF分析（5xxx开头自动识别为沪市）
python3 scripts/find_best_sma.py --symbol 510050

# 自定义扫描范围
python3 scripts/find_best_sma.py --symbol 600519 --start 5 --end 200 --step 5

# 自定义参数（无忧线更宽松的门槛）
python3 scripts/find_best_sma.py --symbol sh000001 --method eternal --bars 3000 --end 500 --min_trades 5
```

### 参数说明

| 参数 | 说明 | 默认 |
|------|------|------|
| `--symbol` | 股票代码（600519 / sh000001 / sz300059 / 00700 / AAPL） | **必填** |
| `--method` | 分析模式：`single`(单均线) / `cross`(双均线) / `both`(一起跑) / `eternal`(无忧线) | `single` |
| `--compare` | 多周期对比（日/周/月自动扫描） | 否 |
| `--strategy` | 策略：`Long Only`(仅做多) / `Buy & Sell`(多空都做) | `Long Only` |
| `--min_trades` | 最少交易次数门槛 | 50（无忧线10） |
| `--start / --end / --step` | 扫描的SMA周期范围与步长 | 10 / 200 / 5 |
| `--period` | 周期：`daily` / `weekly` / `monthly` | `daily` |
| `--bars` | 回测K线数量 | 1200 |
| `--top` | 展示前N候选 | 10 |
| `--mode` | `brute`(暴力枚举) / `knn`(KNN增强) | `brute` |
| `--knn_k` | KNN近邻数 | 7 |

### 可选高级参数

| 参数 | 说明 |
|------|------|
| `--xueqiu-token` | 雪球 xq_a_token，启用雪球数据源增强 |
| `--stooq-apikey` | stooq.com API Key（免费），启用stooq数据源兜底 |
| `--custom-api` | 自定义数据源URL模板，支持 `{symbol}` `{period}` `{count}` 占位符 |

> 💡 以上高级参数均为可选项，零配置情况下所有基础功能完全可用。

## 注意事项

- ⚠️ 历史回测不代表未来收益，所有结果仅供研究参考，不构成投资建议
- ⚠️ 无忧线仅适用于大盘蓝筹和宽基指数，不适用于小盘股
- 扫描范围越大计算越慢；默认 10~200/步长5 约 39 次回测
