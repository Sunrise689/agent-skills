## 第一章 单根K线形态

> 单根K线是构成所有组合的基础单元。判断单根K线的信号强弱，核心看三要素：**实体大小**（多空力量对比）、**影线长短**（攻防痕迹）、**所处位置**（高位/低位/上涨途中/下跌途中/盘整）。"位置决定性质"——同一根K线出现在不同位置含义可能完全相反（如射击之星 vs 倒锤头线、吊颈线 vs 锤头线）。

### 1.1 阳线系列

#### 1.1.1 大阳线（长阳线/长白实体/巨阳线）
- **定义与特征**：收盘价远高于开盘价的阳线，实体修长（通常无或只有很短的上下影线，光头光脚大阳线最标准）。K线颜色为红色/白色（传统日式画法）。
- **技术含义**：**多空力量由多方压倒性掌控**。但信号方向取决于出现位置：
  - 谷底大阳线/低位大阳线/中位大阳线 → **看涨信号**，可买进或持股待涨
  - 高位大阳线/反弹大阳线/连续大幅上涨后的大阳线 → **看跌信号**（往往是赶顶或诱多）
  - 周/月/年K线连续大阳线叠在一起 → **重要见顶信号**
- **识别要点/实战注意事项**：
  - 界定大阳线应遵循"**少数原则+相对原则**"：大阳线在全部K线中应占少数；中小盘股实体涨幅≥8%、超级大盘股≥6%、大盘指数≥4%可认定为大阳线；实际操作中接近标准（如7.8%~7.9%）也应认定，不要死抠数据。（来源：第九册No.12-13）
  - 光头光脚大阳线（开=最低、收=最高）信号最强；带较长影线的大阳线信号略弱。
  - 巨阳线（涨幅极大的大阳线）后**实战法则**：①回调跌破实体上端1/3处→减仓；②跌破实体1/2处→全部抛出；③盘整时间过长必跌。（来源：第七册上第二章）
  - 月K线巨阳线操作：涨幅超过100%先锁定利润；实体上端1/3被吞没全抛；加速形式/叠罗形式（连续巨阳）见顶概率大。（来源：第七册上第二章）
  - 涨停一字线（极端大阳线）可被主力用作**诱多骗线**，必须结合位置、换手率、大盘环境综合判断。（来源：第七册上、第七册下）
  - 日K线大阳线出现后仅几交易日即被后面阴线吞吃 → **反弹大阳线**，是趋势转弱信号。（来源：第九册中篇实战题）
  - 大阳线实体中点构成后续回调的重要支撑位（尼森）。
- **来源**：第一册P20-23；第七册上P119-122；第七册下；第九册No.8、12、14；尼森1第4章；尼森2第2章；尼森3第2章"长白实体"

#### 1.1.2 中阳线、小阳线
- **定义与特征**：中阳线实体中等（涨幅约3%-7%）；小阳线实体短小（涨幅0.5%-3%），可带上下影线。
- **技术含义**：
  - 中阳线：多方力量占优但优势不明显，需结合位置和前后K线判断。
  - 小阳线：多空拉锯、多方小胜，单独出现意义不大；连续小阳线在低位慢慢攀升（冉冉上升形/徐缓上升形）则是看涨信号。
- **识别要点**：小阳线实体过小、上影线过长时，若出现在高位要警惕"滞涨"。
- **来源**：第一册K线一览表；第九册No.3；尼森3第2章

#### 1.1.3 光头阳线（开盘秃阳线/捉腰带线·阳线版）
- **定义与特征**：收盘价=最高价（无上影线），开盘价不等于最低价（可有下影线）；如果开盘价=最低价且收盘价=最高价，就是光头光脚大阳线。开盘价为当日最低价光头阳线即**看涨捉腰带线**（尼森）。
- **技术含义**：看涨信号。低位光头光脚阳线是强烈买进信号；上涨途中光头阳线说明多方强劲。
- **识别要点**：看涨捉腰带线（尼森）：开盘价即为最低价，之后一路上行形成长白实体，常为触底反弹信号；若出现在高位则需警惕后续反转。
- **来源**：尼森1第6章"捉腰带线"；尼森2第4章；尼森3第3章

### 1.2 阴线系列

#### 1.2.1 大阴线（长阴线/长黑实体）
- **定义与特征**：收盘价远低于开盘价的阴线，实体修长（通常无或只有很短的上下影线，光头光脚大阴线最标准），颜色为绿色/黑色。
- **技术含义**：**空方力量压倒性占优**。位置决定性质：
  - 连续下跌后低位大阴线（尤其是跌停大阴线）→ 可能是**赶底信号**（最后一跌），需观察次日是否止跌
  - 上涨后高位大阴线 → **强烈见顶信号**
  - 反弹后大阴线 → 反弹结束、继续下跌
  - 周/月K线大阴线吞吃前面大阳线（月K线穿头破脚）→ **战略看空**
- **识别要点/实战注意事项**：
  - 量化标准同大阳线（反向）：中小盘股实体跌幅≥8%、大盘股≥6%、大盘指数≥4%可认定为大阴线。
  - 光头光脚大阴线（开=最高、收=最低）信号最强。
  - "断头铡刀"是均线范畴，但大阴线跌破多条均线/吞吃前面多根K线时（穿头破脚）信号极其凶险。
  - 连续下跌后出现大阴线+后面中阳线嵌在阴线实体中间 → 构成"身怀六甲"见底信号，不宜再盲目杀跌。（来源：第九册下篇难点题）
  - 高开出逃形：大幅高开低走大阴线，是主力出逃信号，常伴巨量。
  - 大阴线实体中点构成后续反弹的重要阻力位（尼森）。
- **来源**：第一册P23-27；第七册上第一章大阴线部分；第九册中篇；尼森1第4章；尼森2第2章；尼森3第2章"长黑实体"

#### 1.2.2 中阴线、小阴线
- **定义与特征**：中阴线实体中等，小阴线实体短小。
- **技术含义**：空方占优但优势不明显（中阴线）；多空拉锯空方略占上风（小阴线），单独意义不大。
- **识别要点**：连续小阴线在高位慢慢滑落（绵绵阴跌形/徐缓下降形）是看跌信号。
- **来源**：第一册K线一览表；尼森3第2章

#### 1.2.3 光头阴线/光脚阴线（捉腰带线·阴线版）
- **定义与特征**：开盘价=最高价（光头阴线，看跌捉腰带线），一路下行形成长黑实体；收盘价=最低价为光脚阴线。
- **技术含义**：看跌信号。高位出现看跌捉腰带线是强烈卖出信号；下跌途中说明空方强劲。
- **识别要点**：捉腰带线属于单根开盘跳空型K线，实体越长、所处位置越极端信号越强。
- **来源**：尼森1第6章；尼森3第3章

### 1.3 十字线家族（同价线类）

> 十字线的本质特征是**开盘价=收盘价**（或几乎相等），多空双方达到盘中平衡。十字线是最重要的反转警示信号之一，但**必须结合趋势位置判断**：上涨趋势后出现十字线才是顶部警告，下降趋势中需更多确认；在横盘区间中出现十字线意义有限。

#### 1.3.1 十字线（小十字线/十字星/Doji）
- **定义与特征**：开盘价=收盘价，上下影线都较短，实体呈"十"字形或极小横线。
- **技术含义**：**多空平衡、趋势可能停顿或反转**。在上升趋势长白实体后出现是顶部警告；在下降趋势中出现提示可能见底但需确认。信号强度弱于长十字线。
- **识别要点**：
  - 长白实体后的十字线：说明多方进攻受挫、空方开始抵抗，应警惕反转。
  - 十字线顶点（上影线顶端）构成阻力位，若被放量突破则上涨恢复；十字线底端构成支撑位，被跌破则下跌继续。
  - 股票市场十字标准较期货宽松——开收盘价只要非常接近即可视为十字，不必完全相等。
  - 十字线颜色：收盘价略高于开盘价呈红色、低于开盘价呈绿色，但十字线颜色几乎无技术意义。（来源：第九册No.18）
- **来源**：第一册K线一览表、P46-48；第九册No.3、18；尼森1第8章"十字线"；尼森2第2章；尼森3第2章"十字星"

#### 1.3.2 长十字线（长十字/长腿十字线/High-Wave Doji类基础形态）
- **定义与特征**：开盘价=收盘价，上下影线都很长，形如"十"字放大版。
- **技术含义**：**转势信号强于小十字线**。
  - 涨势中出现（特别是高位）→ **见顶信号**
  - 连续加速下跌后出现 → **见底回升信号**
- **识别要点/实战注意事项（长十字线7条操作法则，第七册）**：
  1. 上影线越长见顶信号越强（普通型/增强型/超强型，影线越长越凶险）
  2. 出现在大幅上涨后/高位才是见顶信号，上涨途中/牛市初中期低位可能是洗盘
  3. 出现在熊市反弹中是反弹结束信号
  4. 周K线、月K线长十字线信号比日K线强得多
  5. 长十字线后需等2-3日K线验证：若后面K线在长十字线下影线下方运行则见顶确认，在实体上方运行则可能是洗盘
  6. 高位放量长十字线是主力出货的典型痕迹
  7. 大涨后出现长十字线+射击之星+螺旋桨等多信号共振，见顶概率极大
  - 实战案例：高位长十字线第二天收小阳线但股价仍收在长十字线下影线处 → 见顶信号基本确认（第九册No.156）；大阳线+长十字线+巨量 → 反弹大阳线+主力出货。（第九册No.80）
- **来源**：第一册P46-48；第七册上P3-16、21-22、313；第九册No.18、80、156；尼森1第8章；尼森3第2章

#### 1.3.3 T字线（蜻蜓十字线/Dragonfly Doji/多胜线）
- **定义与特征**：开盘价=收盘价=最高价（无上影线或极短上影线），下影线很长，形如"T"字。
- **技术含义**：位置决定性质——
  - 低位/连续大跌后：**见底信号**（下档支撑强劲，多方反击成功）
  - 高位/连续大涨后：**见顶信号**（多空分歧激烈，主力出货诱多）
- **识别要点**：
  - T字线常常是主力控盘的表现：低位T字线常是主力试盘/拉升信号；高位T字线（尤其是涨停T字）常是主力拉高出货。
  - 下影线越长、对应的时间级别越高（周/月K线），信号越强。
  - 非标准T字线（上影线极短）按"基本像谁归谁"原则识别为T字线变化图形。（来源：第九册No.22）
- **来源**：第一册K线一览表P37-40；第七册；第九册No.22；尼森2第2章"蜻蜓十字"；尼森3第2章

#### 1.3.4 倒T字线（墓碑十字线/Gravestone Doji/上档倒T字线/下跌转折线）
- **定义与特征**：开盘价=收盘价=最低价（无下影线或极短下影线），上影线很长，形如倒"T"字；又称灵位十字线/墓碑十字。
- **技术含义**：位置决定性质——
  - 上涨后高位倒T字线 → **强烈见顶信号**（上档抛压沉重，多方冲高失败）
  - 下跌后低位倒T字线（配合跳空/阳线）→ 可能是见底信号（需后续阳线确认）
- **识别要点**：
  - 墓碑十字线（尼森）：开盘价=收盘价=最低价，上影线极长，盘中一度冲高但收盘被打回原位，出现在高位时是最凶的见顶信号之一。
  - 非标准倒T字线（下影线极短）按"基本像谁归谁"原则归为倒T字线变化图形。（来源：第九册No.22）
  - 倒T字线+射击之星+十字线组合（"三星线"）见顶信号强烈。（来源：第九册No.107）
- **来源**：第一册K线一览表P40-43；第七册；第九册No.22、107；尼森1第8章"墓碑十字线"；尼森2第2章；尼森3第2章

#### 1.3.5 一字线（四价合一线）
- **定义与特征**：开盘价=收盘价=最高价=最低价，四价合一，呈一字横线。A股涨停/跌停时出现（±10%或±20%涨跌幅限制下整日封板）。
- **技术含义**：
  - 涨停一字线：低位连续涨停一字是强势拉升；高位涨停一字线要警惕主力利用一字板诱多出货。
  - 跌停一字线：高位跌停一字是凶险下跌信号；连续跌停一字是极度恐慌信号。
- **识别要点**：
  - 低位/上涨初期涨停一字 → 坚决持股
  - 连续大涨后出现涨停一字被打开+巨量 → 见顶风险陡增
  - 跌停一字线（一字跌停）在高位出现必须第一时间出逃
  - 主力可能利用一字线制造"买不到"或"卖不出"的心理预期进行诱多或逼空。（来源：第七册上、第七册下）
- **来源**：第一册K线一览表；第七册上P113-118；第七册下；尼森1

#### 1.3.6 螺旋桨K线（高浪线/风高浪大线/Spinning Top-High Wave基础形态）
- **定义与特征**：实体很小（可阴可阳），上下影线都很长，形如飞机螺旋桨。实体一阴一阳性质相同。
- **技术含义**：转势信号（与长十字线相同），信号强烈。
  - 涨势中出现 → **后市看跌**（见顶信号）
  - 连续加速下跌行情中出现 → **见底回升信号**
- **识别要点/实战注意事项**：
  - 螺旋桨+长十字线+射击之星组合（双星线/三星线）见顶信号极强。（第九册No.98）
  - 周K线螺旋桨出现后，若指数跌破螺旋桨下影线 → 全部抛空离场。（习题集第二单元）
  - 低位螺旋桨+大阴线+两根阳线 → 可合成早晨之星见底信号。（第九册No.205）
  - 塔形顶"横梁"由3根螺旋桨并排构成 → 极其凶险的见顶信号。（第九册No.96）
  - 3根及以上连续/不连续的高浪线（风高浪大线，尼森）出现 → 很大概率反转。
- **来源**：第一册P48-51；第七册上P3-13；第七册下；第九册No.19、80、96、98、205；习题集；尼森2第4章"风高浪大线"；尼森3第2章"高浪线"

#### 1.3.7 纺锤线（Spinning Top/小实体线）
- **定义与特征**（尼森）：实体很小，上下影线也较短（相对高浪线而言影线不特别长），是一种多空胶着、犹豫不决的K线。
- **技术含义**：
  - 单独出现方向不明，常为趋势停顿信号
  - **低位+放量**纺锤线 → 筹码积聚，**看涨**（主力吸货）
  - **高位+放量**纺锤线 → 筹码派发，**看跌**（主力出货）
  - 在盘整区间频繁出现纺锤线 → 等待方向选择
- **识别要点**：纺锤线是孕线形态的重要组成部分（第二根小实体为纺锤/十字时构成孕线）。
- **来源**：尼森2第2章"小实体"；尼森3第2章"纺锤线"

### 1.4 长影线反转K线

> 这组K线的核心特征是**单侧影线极长、实体小**，是典型的位置决定信号方向的形态：同一形态在涨势末端叫"射击之星/吊颈线"（看跌），在跌势末端叫"倒锤头线/锤头线"（看涨）。本质是**一方试探后被打回原形，揭示潜在力量反转**。

#### 1.4.1 锤头线（锤子线/Hammer）
- **定义与特征**：出现在下跌趋势末端。K线实体很小（可阴可阳，阳线信号略强），位于价格区间上端；**下影线极长**（≥实体长度2-3倍）；上影线极短或没有；形如榔头。
- **技术含义**：**见底反转信号**，看涨。
- **识别要点/实战注意事项**：
  - **位置条件**（最重要）：必须出现在**大幅下跌之后**（跌势末端）才叫锤头线，否则只是普通下影线。
  - **形态条件**（尼森2/3精确判定）：下影线长度≥实体的2-3倍；实体位于当日价格区间上端；上影线越短越好；阳线锤头比阴线锤头信号稍强（但阴线锤头也有效）。
  - **量能条件**：若锤头线当日成交量明显放大 → 见底可靠性增强。
  - **确认条件**（实战纪律）：激进者可在锤头线当日尾盘少量试水；稳健者应等待次日（或2-3日内）出现收盘价高于锤头线实体的阳线**回抽确认支撑**后再加码买入。止损点设在锤头线最低点下方。
  - 下影线越长、成交量越大、前面跌势越猛 → 锤头见底信号越强。（第一册+尼森2）
  - 阳线锤头线信号强于阴线锤头线（第七册第九册No.17）。
- **来源**：第一册P27-29；第九册No.17；尼森1第4章；尼森2第3章；尼森3第3章"锤子线+弹簧线"

#### 1.4.2 吊颈线（上吊线/Hanging Man）
- **定义与特征**：出现在上涨趋势末端。K线实体很小（可阴可阳，阴线信号更强），位于价格区间上端；**下影线极长**（≥实体长度2-3倍）；上影线极短或没有；形状与锤头线完全相同，位置相反——挂在高位像绞刑架上垂下的人。
- **技术含义**：**见顶反转信号**，看跌。
- **识别要点/实战注意事项**：
  - **位置条件**（最重要）：必须出现在**大幅上涨之后/高位**才叫吊颈线。
  - **形态条件**：同锤头线（下影线≥实体2-3倍、实体居上、上影短），**阴线吊颈比阳线吊颈更看跌**（与锤头相反）。
  - **确认条件**（铁律，尼森强调）：**必须等次日收盘价低于吊颈线实体**，才能确认转熊！如果次日收盘价高于吊颈线收盘价（阳线收过吊颈顶），则转熊信号被化解。
  - **量能与细节**：突然跳空高开、成交量急剧放大、当日以大涨报收的吊颈线——是主力刻意做线，欺骗性强但同时暴露主力拉高出货的迫切心情，见顶可能性更大。（来源：第九册中篇No.68）
  - 吊颈线误判陷阱：看似下影线触及均线支撑，但下影线触及支撑只是假象，吊颈才是本质。（第九册No.100）
  - 周K线/月K线吊颈线信号比日K线强得多。
- **来源**：第一册P29-31；第七册上P22-24；第九册No.17、68、100；尼森1第4章；尼森2第3章；尼森3第3章"吊颈线确认原则"

#### 1.4.3 射击之星（流星线/Shooting Star/扫帚星）
- **定义与特征**：出现在上涨趋势末端。K线实体很小（可阴可阳），位于价格区间下端；**上影线极长**（≥实体长度2-3倍）；下影线极短或没有；形如流星划过天际。
- **技术含义**：**见顶反转信号**，看跌。
- **识别要点/实战注意事项**：
  - **位置条件**：必须出现在**大幅上涨之后**才是射击之星。
  - **形态条件**（尼森）：上影线≥实体2倍；实体居下；下影线极短；理想情况实体与前一交易日K线之间有跳空缺口——**跳空缺口越大反转概率越大**。
  - **量能与位置**：射击之星当日放出巨量是主力出货痕迹；心理价位（整数关口/前期高点附近）的射击之星更有效。
  - 两根射击之星构成"平顶"（跨度越大见顶概率越大）。（第九册No.71）
  - 长上影线是射击之星的核心：上影线越长、出现在月K线上做空力量越强（月K线上影线长可预示未来长期下跌）。（第九册No.9）
  - 实体为阴线的射击之星信号略强于阳线。
- **来源**：第一册P33-35；第七册上P18-19、1-49；第九册No.9、17、71、72、84、92、107；尼森1第5章"流星线"；尼森2第4章；尼森3第3章"流星线+上插线"

#### 1.4.4 倒锤头线（倒锤子线/Inverted Hammer）
- **定义与特征**：出现在下跌趋势末端。K线实体很小（可阴可阳），位于价格区间下端；**上影线极长**（≥实体长度2倍）；下影线极短；形状与射击之星完全相同，位置相反。
- **技术含义**：**见底反转信号**，看涨（但信号强度弱于锤头线，需次日确认）。
- **识别要点/实战注意事项**：
  - **位置条件**：必须出现在**大幅下跌之后**才是倒锤头线。
  - **形态条件**：同射击之星（上影≥实体2倍、实体居下），**阳线倒锤头略强于阴线**。
  - **确认条件**（关键）：次日必须**跳空高开或收出阳线且收盘价高于倒锤头实体**，才能确认见底信号。原因：倒锤头上影线代表上方抛压，需要次日买盘力量证实多方消化了这部分抛压。
  - 倒锤头线信号弱于锤头线，常作为辅助见底信号使用。
  - 阳线倒锤头信号强于阴线倒锤头（第七册第九册No.17）。
- **来源**：第一册P31-33；第九册No.17；尼森1第4章；尼森3第3章"倒锤子线"

> **小结——长影线K线识别口诀**（位置+形态+确认）：
> - 高位长下影=吊颈线，次日收盘低于实体才确认看跌；低位长下影=锤头线，回抽确认支撑后看涨。
> - 高位长上影=射击之星，跳空越大、量越大越危险；低位长上影=倒锤头，次日高开/阳线确认才看涨。
> - 实体位置+影线方向+趋势位置，三者缺一不可。

#### 1.4.5 弹簧线（Spring，尼森3补充）
- **定义与特征**（尼森特有）：价格短暂跌破支撑位（如前期低点、密集成交区下沿）后迅速弹回，形成一根带长下影线的K线（属于锤头线的变体/加强版）。
- **技术含义**：**看涨信号**（空头陷阱完成），主力借跌破支撑洗盘吸筹后快速拉回。
- **识别要点**：跌破支撑是假突破（弹簧被压下后反弹），快速收回是关键；后续收盘价站稳支撑位之上可确认。
- **来源**：尼森3第3章"锤子线+弹簧线"

#### 1.4.6 上插线（Upthrust，尼森3补充）
- **定义与特征**（尼森特有）：价格短暂突破阻力位（如前期高点、密集成交区上沿）后迅速回落，形成一根带长上影线的K线（属于射击之星的变体/加强版）。
- **技术含义**：**看跌信号**（多头陷阱完成），主力借突破阻力诱多出货后快速回落。
- **识别要点**：突破阻力是假突破，快速回落收在上影线是关键；后续收盘价跌破阻力位可确认。
- **来源**：尼森3第3章"流星线+上插线"

## 第二章 双根K线组合形态

> 双根K线组合通过两根连续K线的实体位置、影线关系、颜色对比揭示短期力量转折或持续。核心观察点：**两根K线实体是否互相吞没/包含、是否跳空、收盘价位置关系、量能变化**。

### 2.1 吞没型（抱线/包线）

#### 2.1.1 底部穿头破脚（看涨吞没/Bullish Engulfing/阳包阴）
- **定义与特征**：出现在下跌趋势中；第一根为阴线（可长可短）；第二根为**大阳线**，其**实体完全包住前一根阴线的实体**（开盘价低于前阴实体开盘价、收盘价高于前阴实体收盘价）；影线是否吞没不重要，只看实体。
- **技术含义**：**强烈的见底反转信号**，后市看涨。信号强度强于曙光初现/好友反攻。
- **识别要点/实战注意事项**（第一册+尼森综合判定）：
  - **位置**：前面必须有明确下跌趋势（哪怕是短期下跌）。
  - **实体吞没程度**：阳线实体**包住的K线数量越多**（不仅吞前一根，还吞前面多根）→ 信号越强。
  - **实体大小对比**：第一天实体越小、第二天实体越长 → 反转力量越大。
  - **量能**：第二天大阳线伴随**超额成交量**（放量）→ 信号更可靠。
  - **变体**：若第一根为十字线（十字胎后接大阳），也属看涨吞没变体，信号很强。
  - **实战应用**：穿头破脚大阳线+下探上涨形同时出现，且回踩55日均线两次止跌+55日均线翘头向上+成交量放大 → 积极跟进做多。（第九册No.101）
  - 新支撑位在吞没阳线实体中点（尼森）。
- **来源**：第一册P70-72；第六册P45-46；第九册No.24、101、205；尼森1第4章"吞没形态"；尼森2第5章；尼森3第3章

#### 2.1.2 顶部穿头破脚（看跌吞没/Bearish Engulfing/阴包阳）
- **定义与特征**：出现在上涨趋势中；第一根为阳线（可长可短）；第二根为**大阴线**，其**实体完全包住前一根阳线的实体**；影线是否吞没不重要，只看实体。
- **技术含义**：**强烈的见顶反转信号**，后市看跌。是最常见、最可靠的顶部反转组合之一。
- **识别要点/实战注意事项**（第七册3要点+尼森补充）：
  - **位置**：必须出现在大幅上涨后/高位。
  - **3个判定要点**（第七册核心）：①阴线实体长度——实体越长越凶；②吞吃K线数量——阴线吞吃前面K线越多（不仅吞前一根阳，还吞前面几根阳）见顶概率越大，吞吃部分不包括上下影线；③出现位置——高位/月K线穿头破脚是战略看空信号。
  - **量能**：第二根阴线放量/天量 → 主力出逃痕迹明显，信号确认。
  - **月K线穿头破脚**：一旦出现，战略看空，杀伤力极大，未来暴跌概率高。（第七册、第九册No.92、176）
  - **高位穿头破脚+高开出逃形+缺口封闭**：多重看跌信号共振，几乎必跌。（第九册No.99）
  - **V形反转陷阱**：高位V形反转+一根大阴线吃掉前面2根涨停一字线形成穿头破脚+除权后冲高天量 → 是假突破/诱多，后市必跌。（第九册No.163）
  - **三重顶+穿头破脚**：第三顶以穿头破脚大阴线出现 → 向下破位是早晚的事，立即卖出。（第九册No.81）
  - 新阻力位在吞没阴线实体中点（尼森）。
- **来源**：第一册P70-72；第六册P41-46；第七册上P42-53、311；第九册No.24、81、92、99、100、163、176；尼森1第4章；尼森2第5章；尼森3第3章

> **穿头破脚与乌云盖顶的关系**：乌云盖顶是"日偏食"——第二天阴线仅深入第一天阳线实体一半以上但未完全吞没；穿头破脚是"日全食"——第二天实体完全包住第一天实体。因此穿头破脚信号强于乌云盖顶。（尼森2比喻）

### 2.2 刺入/覆盖型（曙光/乌云类）

#### 2.2.1 曙光初现（刺透形态/斩回线/Piercing Pattern）
- **定义与特征**：出现在下跌趋势中；第一根为**大阴线/中阴线**；第二根为**大阳线/中阳线**，其**开盘价低于第一根阴线的最低价**（即跳低开盘创出新低），**收盘价深入第一根阴线实体的中点以上**（刺入≥50%）。
- **技术含义**：**见底反转信号**，后市看涨。信号强度弱于旭日东升和底部穿头破脚，强于好友反攻。
- **识别要点/实战注意事项**：
  - **刺入深度**：收盘价刺入阴线实体越深（>50%）→ 信号越强；仅进入1/3左右为较弱信号。
  - **开盘条件**：必须**跳低开盘低于前阴线最低价**（向下跳空），才是标准刺透；如果仅低开但未低于前低，信号弱。
  - **量能**：第二根阳线放量配合更可靠。
  - **双刺透形态**（尼森2补充）：若标准刺透出现后再次出现刺透（或阳线再创新高），是更强的反转确认信号。
- **来源**：第一册P51-52；第九册No.23；尼森1第4章；尼森2第6章"刺透形态/双刺透"；尼森3第3章

#### 2.2.2 乌云盖顶（Dark Cloud Cover）
- **定义与特征**：出现在上涨趋势中；第一根为**大阳线/中阳线**；第二根为**大阴线/中阴线**，其**开盘价高于第一根阳线的最高价**（即跳空高开创出新高），**收盘价深入第一根阳线实体的中点以下**（深入>50%）。
- **技术含义**：**见顶反转信号**，后市看跌。信号强度弱于倾盆大雨和顶部穿头破脚，强于淡友反攻。
- **识别要点/实战注意事项**：
  - **深入深度**：阴线收盘价深入阳线实体中点以下才算标准；仅切入1/3左右为非标准乌云盖顶，信号较弱。
  - **开盘条件**：必须**跳高开盘高于前阳线最高价**（向上跳空）才是标准乌云盖顶。
  - **实战叠加信号**：射击之星之后反弹+乌云盖顶 → 反弹结束信号。（第九册No.72）；高位大阳线（涨停大阳）+后面中阴线构成乌云盖顶+大阳线开盘价被跌破 → 上升行情结束。（第九册No.77）；高位乌云盖顶+MACD死叉+高开出逃形+巨量 → 主力出货痕迹明显，必跌图形。（第九册No.102）
  - 乌云盖顶是"日偏食"，与穿头破脚（日全食）对比记忆。
- **来源**：第一册P52-55；第九册No.23、72、77、102；习题集填空8；尼森1第4章；尼森2第6章；尼森3第3章

#### 2.2.3 旭日东升
- **定义与特征**：出现在下跌趋势中；第一根为**大阴线**；第二根为**大阳线**，其**开盘价高于第一根阴线的收盘价**（跳高开盘），收盘价高于第一根阴线的开盘价（完全收复阴线实体）。
- **技术含义**：**见底反转信号强于曙光初现**，后市看涨。
- **识别要点**：阳线收盘价越高（深入阴线前的位置越多）→ 信号越强；如阳线收盘价远超阴线开盘价，信号更强。
- **来源**：第一册P56-58；第九册No.23

#### 2.2.4 倾盆大雨
- **定义与特征**：出现在上涨趋势中；第一根为**大阳线**；第二根为**大阴线**，其**开盘价低于第一根阳线的收盘价**（跳低开盘），收盘价低于第一根阳线的开盘价（完全吃掉阳线实体）。
- **技术含义**：**见顶反转信号强于乌云盖顶**，后市看跌。（习题集填空1、习题33答案）
- **识别要点**：收盘价越低、阴线实体越长 → 信号越凶；第二根阴线跳低开盘说明多方无力守阵地，空方直接打压。
- **来源**：第一册P56-58；第九册No.23；习题集选择题33

#### 2.2.5 好友反攻（反击线/约会线·底部/Bullish Counterattack）
- **定义与特征**：出现在下跌趋势中；第一根为**大阴线**；第二根为**阳线**（可大可小），其**收盘价与第一根阴线收盘价相同或相近**（两根K线"约会"到同一收盘价水平），开盘价向下跳空。
- **技术含义**：**见底反转信号**，但力度弱于曙光初现。属于初步止跌信号，需要后续确认。
- **识别要点**：两根K线收于同一价位是关键；第二根阳线实体越长、量越大信号越可靠。
- **来源**：第一册K线一览表；尼森1第6章"反击线"；尼森3第3章

#### 2.2.6 淡友反攻（反击线/约会线·顶部/Bearish Counterattack）
- **定义与特征**：出现在上涨趋势中；第一根为**大阳线**；第二根为**阴线**（可大可小），其**收盘价与第一根阳线收盘价相同或相近**，开盘价向上跳空。
- **技术含义**：**见顶反转信号**，力度弱于乌云盖顶。
- **识别要点**：同好友反攻反向；若第二根阴线放量、长上影则信号加强。
- **来源**：第一册K线一览表；尼森1第6章；尼森3第3章

### 2.3 孕线（身怀六甲/母子线/Harami）

#### 2.3.1 顶部身怀六甲（看跌孕线/Bearish Harami）
- **定义与特征**：出现在上涨趋势中；第一根为**长阳线**（或大阳线）；第二根为**小实体K线**（小阳/小阴/十字/纺锤线均可），且第二根的**实体和影线完全被第一根实体包裹**（"母亲怀孕"形态：长K线为母，小K线为子）。
- **技术含义**：**见顶信号**，表明上升势头停顿、可能反转，信号强度弱于穿头破脚。
- **识别要点/实战注意事项**：
  - 第二根实体越小（十字胎/十字孕线最强）→ 反转概率越大。
  - **快速上涨后出现身怀六甲+MACD顶背离** → 见顶信号明确，趁未大跌赶快卖出。（第九册No.70）
  - **第二根为十字线即"十字胎"**（十字孕线），信号极强。
  - 高位身怀六甲后出现中阴线确认 → 见顶有效。（第九册No.167）
- **来源**：第一册P67-70；第九册No.25、70、167；尼森1第6章"孕线形态"；尼森2第7章；尼森3第3章

#### 2.3.2 底部身怀六甲（看涨孕线/Bullish Harami）
- **定义与特征**：出现在下跌趋势中；第一根为**长阴线**（或大阴线）；第二根为**小实体K线**（小阴/小阳/十字），被第一根实体完全包裹。
- **技术含义**：**见底信号**，表明下跌势头停顿、可能反转。
- **识别要点**：
  - 连续下跌后大阴线+中阳线嵌在阴线实体中间构成孕线 → 见底可能性增加；只要后续K线在孕线形态上方运行即可积极做多。（第九册No.96）
  - 十字胎信号最强。
  - **高位包孕/高价包孕**（尼森3补充）：第二根小实体位于第一根长阳线**上端**（而非中间）时，常是**整固而非反转**信号，期权交易者可据此卖空波动率。
- **来源**：第一册P67-70；第九册No.25、96；尼森1第6章；尼森2第7章；尼森3第3章"高价包孕/十字孕线"

### 2.4 平头/平底（镊子线/Tweezer）

#### 2.4.1 平顶（钳子顶/Tweezer Top）
- **定义与特征**：两根或多根K线的**最高价相同或极相近**（构成水平顶线），K线实体/颜色/上下影线不一定相同。可由相邻K线或间隔1-2日的K线构成。
- **技术含义**：**见顶信号**。
- **识别要点**：
  - 构成平顶的K线可以是任何类型（影线/实体相同高价均可）。
  - 两根射击之星的上影线高点构成平顶 → 跨度越大见顶概率越大。（第九册No.71）
  - 平顶+穿头破脚/乌云盖顶/吊颈线等其他看跌形态同时出现 → 信号叠加更可靠。
- **来源**：第一册K线一览表P72-75；第九册No.71；尼森1第6章"平头顶部形态"

#### 2.4.2 平底（钳子底/Tweezer Bottom）
- **定义与特征**：两根或多根K线的**最低价相同或极相近**（构成水平底线）。
- **技术含义**：**见底信号**。
- **识别要点**：平底+锤头线/曙光初现/穿头破脚等其他看涨形态共振信号更强。
- **来源**：第一册P72-75；习题集选择题36；尼森1第6章

### 2.5 其他双根形态

#### 2.5.1 尽头线
- **定义与特征**：出现在上涨/下跌趋势中。
  - 上升尽头线（见顶）：第一根为带长上影的大阳/中阳；第二根为小K线（小阳/小阴/十字），其**实体和影线完全被第一根上影线范围内覆盖**（注意是影线内，不是实体内，区别于孕线）。
  - 下降尽头线（见底）：第一根为带长下影的大阴/中阴；第二根小K线被第一根下影线范围覆盖。
- **技术含义**：趋势走到尽头的信号——上升尽头线见顶、下降尽头线见底。
- **识别要点**：第二根K线实体越小、影线越短 → 反转信号越明确。
- **来源**：第一册P152-154；第九册No.25

#### 2.5.2 搓揉线（洗盘线/搓板线）
- **定义与特征**：由两根K线组成——第一根为**T字线**（长下影），第二根为**倒T字线**（长上影），两根K线实体都很小。像"搓衣服"一样上下洗盘。
- **技术含义**：位置决定性质——
  - 上涨途中搓揉线 → **洗盘信号**，主力洗盘后继续上涨（中继）
  - 高位/涨势末端搓揉线 → **见顶信号**
- **识别要点**：搓揉线是主力控盘洗盘/出货的特征线；上涨途中出现且缩量→洗盘；高位放量+搓揉线→出货。
- **来源**：第一册K线一览表

#### 2.5.3 跳空上扬形（升势鹤鸦缺口/Upside Tasuki Gap，尼森"向上跳空并列阴阳线"类相关）
- **定义与特征**：上涨途中，第一根阳线后出现**向上跳空缺口**，缺口后出现一根阴线但未**回补缺口**（即阴线收盘价仍高于缺口上端）。
- **技术含义**：**中继看涨信号**（上涨过程中的短暂休整），后续继续上涨。
- **识别要点**：关键是缺口未被回补；若阴线收盘价回补缺口，则形态失败需警惕。
- **来源**：第一册K线一览表P98-101；尼森1第7章"向上跳空并列阴阳线"

#### 2.5.4 高位并排阳线（升势恋人缺口/肩并肩缺口/Upward Gap Side-by-Side White Lines，尼森"跳空并列白色蜡烛线"看涨版）
- **定义与特征**：上涨过程中出现**向上跳空缺口**，缺口后出现两根**大小相当的阳线**（两根白色实体并排），开盘价接近，形成肩并肩形态。
- **技术含义**：**中继看涨信号**（强势整理后继续上行）。
- **识别要点**：两根阳线实体大小相近、同处缺口上方；缺口不被回补是前提。
- **来源**：第一册K线一览表P101-104；尼森1第7章"跳空并列白色蜡烛线"

#### 2.5.5 低位并排阳线（Downside Gap Side-by-Side White Lines，尼森"向下跳空并列白色蜡烛线"看跌版）
- **定义与特征**：下跌过程中出现**向下跳空缺口**，缺口后出现两根并排阳线（反弹），但未能回补缺口。
- **技术含义**：**中继看跌信号**（下跌中短暂反弹，后续继续下跌），注意不是见底信号。
- **识别要点**：两根阳线只是技术性反弹，无法回补缺口说明空方仍控盘。
- **来源**：第一册K线一览表P78-79；尼森1第7章

#### 2.5.6 双飞乌鸦（Two Crows/Upside Gap Two Crows）
- **定义与特征**：上涨趋势中——第一根大阳线之后，**向上跳空**出现一根小阴线；再后面一根阴线开盘价高于第一根阴线开盘价但收盘价更低（实体包住前一根小阴线），两根阴线形似两只乌鸦蹲在枝头。
- **技术含义**：**见顶信号**。向上跳空双乌鸦比普通双飞乌鸦更凶险（"跳空双乌鸦"为更强变体）。
- **识别要点**：两根阴线都未能填补向上跳空缺口但实体不断向下延伸；第三根若再出大阴线则确认。
- **来源**：第一册P127-129；尼森1第7章

#### 2.5.7 镊子线（三根/两根K线类，亦见于平头顶底）
- **定义与特征**：三根K线——第一根大阳线/大阴线、中间一根小K线、第三根大阴线/大阳线，三根K线的最高价（顶部镊子）或最低价（底部镊子）大致相等。
- **技术含义**：顶部镊子线见顶、底部镊子线见底。
- **识别要点**：因K线实体形如镊子夹物得名；实体大小对称、高低点一致是关键。
- **来源**：第一册K线一览表

#### 2.5.8 分手线（Separating Lines/反向分离线）——尼森补充形态
- **定义与特征**（尼森特有）：两根K线**开盘价相同**；第一根为阴线、第二根为阳线（看涨分手线，出现在上涨途中）；或第一根阳线、第二根阴线（看跌分手线，出现在下跌途中）。颜色相反但同开市价，俗称"分手"——与反击线（约会线/好友反攻）相反：反击线是同收市价相反颜色（"约会"），分手线是同开市价相反颜色（"分手"）。
- **技术含义**：**持续形态**（中继信号），趋势将按原方向继续。看涨分手线继续上涨；看跌分手线继续下跌。
- **识别要点**：不要与反击线混淆——反击线同收市价→反转；分手线同开市价→中继。
- **来源**：尼森1第7章"分手线"

#### 2.5.9 十字线发展形态（十字星与其他线组合，尼森2补充）
- **定义与特征**（尼森2）：大实体后紧跟十字线，且十字线后的第三根K线对十字线的突破方向确认趋势——长白+十字+阴线深入阳线 → 看跌；长黑+十字+阳线站回阴线实体上 → 看涨。
- **技术含义**：十字线后的第三根K线方向，是对趋势转折的最终确认。
- **识别要点**：十字线是警告，第三根才是信号。
- **来源**：尼森2第6章"十字线发展/混合形态"

#### 2.5.10 混合形态/合成蜡烛线（尼森2补充）
- **定义与特征**（尼森2）：可将多根K线合并为一根"合成蜡烛线"观察——以第一根开盘价为开盘价、最后一根收盘价为收盘价、期间最高价为最高、最低价为最低。若合成后呈现典型反转形态（如合成锤头/吞没/乌云），则该组合具有相应反转意义。
- **技术含义**：合成蜡烛帮助理解多根K线组合的综合力量方向。
- **识别要点**：黄昏之星/早晨之星变化图形常用合成法识别（如两根阳线合成第一根阳、两根阴线合成第三根阴，即可还原标准形态，见第九册No.66黄昏十字星合成例）。
- **来源**：尼森2第6章"混合形态"；尼森3第2章"合成蜡烛"；第九册No.66

## 第三章 三根及多根K线组合形态

### 3.1 星线家族（Star Family）——最经典的三K线反转组合

> 星线组合由三根K线构成：**长实体K线 → 跳空小实体（星）→ 反向长实体K线**。中间"星"的部分是多空转折的关键——原本趋势方向的能量被跳空小实体打断，第三根反向实体确认趋势反转。

#### 3.1.1 早晨十字星（十字启明星/Morning Doji Star）
- **定义与特征**：出现在下跌末端。①第一根为**大阴线**（继续下跌）；②第二根为**十字线**（开盘价=收盘价，与第一根阴线实体之间有向下跳空缺口）；③第三根为**大阳线**，其**收盘价深入第一根阴线实体**（≥1/2处为标准）。
- **技术含义**：**强烈见底信号**（强于普通早晨之星），后市看涨。
- **识别要点/实战注意事项**：
  - 中间为十字线而非一般小实体 → 反转力量更强。
  - 第三根阳线深入第一根阴线越深 → 信号越强。
  - 月K线早晨十字星+最后一根阳线放量 → 见底意味更浓；下个月股价继续收阳且站稳最后一根K线收盘价之上 → 积极做多。（第九册No.64）
  - 股市中实体间跳空不一定严格要求（弹性），越接近标准可靠性越高。
- **来源**：第一册P59-60；第九册No.27、64；尼森1第5章；尼森2第7章；尼森3第3章

#### 3.1.2 早晨之星（启明星/Morning Star/希望之星）
- **定义与特征**：出现在下跌末端。①第一根**大阴线**；②第二根**小实体K线**（小阳/小阴/十字/纺锤，与第一根阴线间有向下跳空缺口）；③第三根**大阳线**，收盘价深入第一根阴线实体≥1/2处。
- **技术含义**：**见底反转信号**，后市看涨。
- **识别要点/实战注意事项**：
  - 第三根阳线切入第一根阴线越深、量能配合越明显 → 信号越强。
  - 周K线早晨之星信号强于日K线（第九册No.104）。
  - 早晨之星变化图形识别（两根阳合成第一根、两根阴合成第三根等）→ 用"合成蜡烛"法还原标准形态识别。
  - 操作：周K线早晨之星出现后不能盲目重仓，应试盘做多；若后续K线在第三根阳线收盘价上方运行可积极跟进；若在其下方运行则观望。（第九册No.104）
- **来源**：第一册P62-64；第六册P282；第九册No.27、104；尼森1第5章；尼森2第7章；尼森3第3章

#### 3.1.3 黄昏十字星（Evening Doji Star）
- **定义与特征**：出现在上涨末端。①第一根**大阳线**；②第二根**十字线**（向上跳空）；③第三根**大阴线**，收盘价深入第一根阳线实体≥1/2处。
- **技术含义**：**强烈见顶信号**（强于普通黄昏之星），后市看跌。
- **识别要点**：
  - 变化图形：两根阳线可合成大阳线、两根阴线可合成大阴线，还原标准黄昏十字星。（第九册No.66）
  - 出现后应减仓；后续股价继续下行则信号确认，坚决抛空离场。
- **来源**：第一册P60-62；第九册No.27、66；尼森1第5章；尼森2第7章；尼森3第3章

#### 3.1.4 黄昏之星（Evening Star）
- **定义与特征**：出现在上涨末端。①第一根**大阳线**；②第二根**小实体K线**（小阳/小阴/十字/纺锤，向上跳空）；③第三根**大阴线**，收盘价深入第一根阳线实体≥1/2处。
- **技术含义**：**见顶反转信号**，后市看跌。最经典、最常见的顶部反转组合之一。
- **识别要点/实战注意事项**（第七册详解）：
  - 第三根阴线切入阳线越深、放量越明显 → 信号越强。
  - **黄昏之星需量能配合+击穿关键点位更危险**（第七册）。
  - 第三根阴线放量 → 主力出货。
  - 黄昏之星+4连阴+10日均线击穿+MACD死叉 → 多重信号见顶。（第九册No.94）
  - 高位涨停大阳线（赶顶）+射击之星+倒T字线（三者构成黄昏之星组合）+放量 → 主力利用创新高诱多出货，后面必有大跌。（第九册No.105）
- **来源**：第一册P64-66；第七册上P56-64；第九册No.27、94、105、181；习题集；尼森1第5章；尼森2第7章；尼森3第3章

#### 3.1.5 弃婴形态（Abandoned Baby）——尼森补充·罕见形态
- **定义与特征**（尼森特有·极端变体）：早晨/黄昏十字星的极端罕见版本。
  - 弃婴底部：①长阴线；②十字线**完全孤立**——与前后两根K线实体、影线之间都有跳空缺口（即十字线前后都留缺口）；③长阳线向上跳空，收盘深入阴线实体。
  - 弃婴顶部：①长阳线；②十字线完全孤立（前后皆跳空）；③长阴线向下跳空，收盘深入阳线实体。
- **技术含义**：**极强反转信号**（比十字启明星/黄昏星更强），罕见但可信度极高。
- **识别要点**：十字线像被遗弃的婴儿左右各留一个缺口，是与普通十字星的关键区别；股市中极少见，出现即高度重视。
- **来源**：尼森1第5章；尼森3第3章

#### 3.1.6 流星形态与倒锤头（已在单根K线中说明；注意与星线区别）
- 单根K线形态已在第一章说明；但流星线若以跳空形式出现（即长白+跳空小实体上影极长），有时视为单根星线变体。
- **来源**：尼森1第5章

#### 3.1.7 三星形态（Tri-Star）——尼森补充·极罕见
- **定义与特征**（尼森特有）：三根十字线——第一根十字线、第二根十字线跳空、第三根十字线反向跳空。三根十字构成"星群"。
- **技术含义**：**极其罕见的强烈反转信号**（比弃婴形态更罕见）。
- **识别要点**：连续三根十字线非常少见；第二根十字星比前后两根位置更高/更低。
- **来源**：尼森1第8章"三星形态"

#### 3.1.8 崩盘十字星（Evening Doji Star极端看跌变体）——尼森3补充
- **定义与特征**（尼森3特有）：类似黄昏十字星但第三根阴线大幅跳空低开、暴跌收盘，十字星+跳空暴跌的组合。
- **技术含义**：崩盘式见顶信号。
- **来源**：尼森3第3章

#### 3.1.9 奇特三川底部（Unique Three River Bottom）——尼森补充
- **定义与特征**（尼森特有·罕见三K线见底）：①第一根长阴线；②第二根带长下影的小实体阴线（类似锤头/吊颈形态），创出新低但收盘离开低点；③第三根为小阳线，实体位于第二根K线的上影线范围内。
- **技术含义**：见底信号。
- **识别要点**：罕见形态；因形似三条河流汇流得名。
- **来源**：尼森1（提及但少见）；尼森3

### 3.2 三兵/三鸦类

#### 3.2.1 红三兵（白色三兵/Three White Soldiers）
- **定义与特征**：连续**三根阳线**，收盘价逐次抬高；每根阳线开盘价位于前一根阳线实体内部（低开一点即上攻），收盘价接近当日最高价；实体逐步上升形成三个红色士兵稳步推进。
- **技术含义**：**看涨信号**（低位出现是强烈买进信号，上涨途中是持续上涨信号）。
- **识别要点/实战注意事项**：
  - 标准红三兵：三根阳线稳步上升、每根实体大小相近、无上影或短上影。
  - 需与前方受阻/停顿形态（见下）区分。
  - 低档红三兵出现在长期盘整后 → 是强烈启动信号。
- **来源**：第一册P84-85；习题集"K线顺口溜"；尼森1第7章；尼森3第3章

#### 3.2.2 前方受阻白色三兵形态（Advance Block）——尼森补充
- **定义与特征**（尼森特有）：三根阳线形态，但**上影线越来越长**、实体越来越小，显示上涨受阻。
- **技术含义**：**看跌预警信号**（在上涨趋势中出现表示多方力量衰减、上档抛压加重，可能见顶）。
- **识别要点**：与标准红三兵区别——红三兵稳步推高无长影；前方受阻三兵第三根带明显长上影、实体缩小。
- **来源**：尼森1第7章；尼森3第3章

#### 3.2.3 停顿形态（深思形态/Deliberation Pattern）——尼森补充
- **定义与特征**（尼森特有）：前两根为长阳线，第三根为**小阳线**（或十字线/纺锤线），且开盘价紧贴第二根收盘价——显示上涨节奏突然停顿、多方"深思"。
- **技术含义**：**见顶预警**（上涨后多方犹豫、能量不济，可能反转）。
- **识别要点**：第三根小实体K线与前方受阻三兵的区别在于——停顿形态第三根实体小但不一定带长上影，只是实体突然变小。
- **来源**：尼森1第7章；尼森3第3章

#### 3.2.4 三只乌鸦（三乌鸦/暴跌三杰/Three Black Crows）
- **定义与特征**：连续**三根阴线**，收盘价逐次下跌；每根阴线开盘价位于前一根阴线实体内部（高开即下挫），收盘价接近当日最低价；三只黑乌鸦栖在枝头。
- **技术含义**：**强烈见顶信号**，后市看跌（暴跌三杰名符其实）。
- **识别要点**：
  - 三只乌鸦出现说明空方已完全控盘，连续三天下跌消化买盘。
  - 三只乌鸦与红三兵反向对称。
- **来源**：第一册P137-138；习题集"K线顺口溜"；尼森1第6章"三乌鸦"

#### 3.2.5 黑三兵
- **定义与特征**：连续三根小阴线，最低价逐次下移，实体较短（区别于三只乌鸦的大阴线）。
- **技术含义**：位置决定——
  - 高位黑三兵 → 见顶信号（空方开始发力）
  - 低位/连续下跌后黑三兵 → 可能是探底信号（最后一跌），需观察是否止跌
  - 上涨途中黑三兵 → 短期回调、洗盘
- **识别要点**：黑三兵实体较小、节奏较三乌鸦温和；连续五阴（高档五阴线）见顶更可靠。
- **来源**：第一册P85-87；习题集"K线顺口溜"

### 3.3 三法类（持续/休整形态）

#### 3.3.1 上升三部曲（升势三鸦/上升三法/Rising Three Methods/Bullish Sanpoh）
- **定义与特征**：上涨途中。①一根**大阳线**；②之后出现**三根或多根短小实体K线**（小阴小阳交替），整体呈小幅回落整理且**未跌破第一根大阳线开盘价**；③最后再出现一根**大阳线**，收盘价创新高。整体像上升途中的一次短暂休整（"涨-休整-涨"）。
- **技术含义**：**中继看涨信号**（强势整理后继续上攻），后市看涨。
- **识别要点**：
  - 中间小K线数量通常为3根，但可多可少（2-5根均可）。
  - 中间小K线实体应在第一根大阳线实体范围内（高低点不破）；若跌破大阳线开盘价则形态失败。
  - 最后一根大阳线必须放量突破创新高。
- **来源**：第一册P107-112；习题集选择题34；尼森1第7章"上升三法"；尼森3第3章

#### 3.3.2 下降三部曲（降势三鹤/下降三法/Falling Three Methods/Bearish Sanpoh）
- **定义与特征**：下跌途中，与上升三法对称。①一根**大阴线**；②三根或多根短小实体K线小幅反弹但**未突破第一根大阴线开盘价**；③最后一根**大阴线**再创出新低。
- **技术含义**：**中继看跌信号**，后市继续下跌。
- **识别要点**：中间小阳线是"逃命波"，最后一根大阴线确认跌势继续。
- **来源**：第一册P127、134-137；尼森1第7章；尼森3第3章

### 3.4 窗口（缺口/Jump/Window）类

> 日语蜡烛图中"窗口"（Window）即西方技术分析的"缺口"（Gap）：两根K线之间存在价格真空地带（前一K线最高价与后一K线最低价之间未成交）。窗口分为向上窗口（后K线最低>前K线最高=向上跳空缺口）和向下窗口（后K线最高<前K线最低=向下跳空缺口）。核心规则（尼森强调）：**窗口是后续走势的支撑（向上窗口）或阻力（向下窗口）；收盘价封闭窗口则原趋势结束（强调收盘价，不是盘中刺穿）**。

#### 3.4.1 上升窗口（向上跳空缺口）
- **定义与特征**：后一根K线的最低价高于前一根K线的最高价，形成向上跳空缺口。
- **技术含义**：**看涨持续信号**；缺口构成后续回调的支撑位。
- **识别要点**（尼森+第一册综合）：
  - 突破性窗口（突破盘整区间的窗口）是最强烈看涨信号。
  - 窗口未被收盘价关闭前支撑有效；三个交易时段（3日）不关闭可确认趋势。
  - 收盘价回补窗口（即收盘价回到缺口下方）→ 上升趋势结束警告。
  - 奔驰窗口（Running Window，尼森3）：由长白实体开启的大窗口，显示多头快速奔驰推进，是最强的向上窗口类型。
- **来源**：第一册缺口章节；尼森1第7章；尼森2第8章；尼森3第3章"奔驰窗口"

#### 3.4.2 下降窗口（向下跳空缺口）
- **定义与特征**：后一根K线的最高价低于前一根K线的最低价，形成向下跳空缺口。
- **技术含义**：**看跌持续信号**；缺口构成后续反弹的阻力位。
- **识别要点**：收盘价回补窗口（收上缺口上方）→ 下降趋势结束警告；向下突破窗口（跌破盘整/支撑）最凶险。
- **来源**：尼森1第7章；尼森2第8章

#### 3.4.3 三窗口理论（三空理论/Three Windows，尼森3补充）
- **定义与特征**（尼森3源自酒田战法）：同一趋势方向上连续出现三个窗口（三个跳空缺口）。
- **技术含义**：**物极必反信号**——三窗口（三空）后原趋势动能耗尽，可能出现反转。
  - 上升趋势三窗口 → 警惕见顶（"三而竭"）
  - 下跌趋势三窗口 → 警惕见底
- **识别要点**：
  - 三空不是马上反转的精确指标，而是警告；必须等**收盘价封闭最后一个窗口**才能确认趋势反转，不能仅凭三个窗口就盲目抄底/逃顶。
  - 酒田战法口诀："三空之后见顶/底"。
- **来源**：尼森3第3章"三窗口理论"

#### 3.4.4 双黑跳空（Double Black Gap，尼森3补充）
- **定义与特征**（尼森3特有）：在下跌趋势中出现向下跳空缺口后，连续出现两根阴线（跳空+双阴线）。
- **技术含义**：**强烈看跌持续信号**，下跌动能极强。
- **来源**：尼森3第3章"双黑跳空"

#### 3.4.5 跳空十字星（Gapping Doji，尼森3补充）
- **定义与特征**（尼森3）：出现跳空缺口后K线为十字线（窗口+十字）。
- **技术含义**：方向待定——若出现在顶部则见顶；出现在底部则见底；关键看后续K线对缺口和十字的突破方向。
- **来源**：尼森3第3章"跳空十字"

#### 3.4.6 跳空下跌三颗星
- **定义与特征**（第一册）：下跌途中，一根阴线后出现向下跳空缺口，缺口后出现三根小星K线（小阴/小阳），未能回补缺口。
- **技术含义**：**见底信号**（空方动能释放殆尽），但需后续阳线确认。
- **来源**：第一册K线一览表P105-107

#### 3.4.7 下跌三颗星
- **定义与特征**：下跌初期/途中出现三根小K线排列，实体不大。
- **技术含义**：**中继看跌信号**（短暂整理后继续下跌）。
- **来源**：第一册K线一览表P130-132

#### 3.4.8 上涨二颗星
- **定义与特征**：上涨初期/途中，连续上涨后出现两根小K线（小阳/小阴）整理。
- **技术含义**：**中继看涨信号**（多方短暂换手后继续上涨）。
- **来源**：第一册K线一览表P97-98

#### 3.4.9 向上/向下跳空并列阴阳线（Tasuki Gap，尼森补充）
- **定义与特征**（尼森特有）：
  - 向上跳空并列阴阳线（升势鹤鸦缺口类）：阳线+向上跳空阳线+阴线；阴线开盘在前阳线实体内部、收盘前阳线实体下方但**未回补跳空缺口**。
  - 向下跳空并列阴阳线：阴线+向下跳空阴线+阳线；阳线未回补缺口。
- **技术含义**：**中继持续信号**。
- **识别要点**：缺口不回补是关键；已在双根K线2.5.3提及跳空上扬形。
- **来源**：尼森1第7章

#### 3.4.10 高价位跳空突破形态/低价位跳空突破形态（High/Low Price Gap Breakout，尼森补充）
- **定义与特征**（尼森特有）：
  - 高价位跳空突破：盘整区间高位出现向上跳空白色阳线 → 突破信号。
  - 低价位跳空突破：盘整区间低位出现向下跳空黑色阴线 → 向下突破信号。
- **技术含义**：**突破信号**（对应西方技术分析"突破缺口"概念在K线中的体现）。
- **来源**：尼森1第7章

#### 3.4.11 孤岛形态（Island Reversal，与窗口组合，尼森2）
- **定义与特征**（尼森2）：一段K线组合被**前后两个相反方向的跳空窗口孤立**出来（如向上跳空高位盘整数日/数周后向下跳空，形成一个被两边窗口孤立的"岛"）。与西方技术图形"岛形反转"对应。
- **技术含义**：**强烈反转信号**（顶部孤岛见顶、底部孤岛见底）。
- **识别要点**：顶部岛形反转杀伤力极大，是2010年4月上证指数3000→2319、2010年12月创业板见顶狂泻的元凶。（第九册引言No.56）
- **来源**：尼森2第7、8章；第九册习题No.23、56

### 3.5 夹线/尖兵/抵抗形

#### 3.5.1 两红夹一黑（两阳夹一阴/Bullish Sandwich）
- **定义与特征**：两根阳线中间夹一根阴线；两根阳线实体较长，中间阴线实体较短，阴线被两根阳线夹持。
- **技术含义**：
  - 上涨途中/低位 → **看涨信号**（多方继续掌控，阴线是洗盘）
  - 高位则需警惕
- **识别要点**：第三根阳线收盘价创新高、收盘价高于中间阴线开盘价是有效形态。
- **来源**：第一册K线一览表P115-117

#### 3.5.2 两黑夹一红（两阴夹一阳/Bearish Sandwich）
- **定义与特征**：两根阴线中间夹一根阳线；两根阴线实体较长，中间阳线实体较短。
- **技术含义**：**看跌信号**（空方掌控，反弹阳线被打回），高位/下跌途中出现尤其凶险。
- **识别要点**：第三根阴线收盘价创新低；高位两黑夹一红是典型卖出信号。
- **来源**：第一册P115-117；习题集填空4

#### 3.5.3 多方尖兵
- **定义与特征**：上涨途中，一根带长上影的K线（冲高试盘），之后几根K线回调整理（不破该阳线开盘价），最后大阳线突破前高。
- **技术含义**：**看涨信号**（主力试盘后发动总攻）。
- **识别要点**：上影线是"尖兵"试探上方抛压；随后整理蓄势+突破是有效形态。
- **来源**：第一册K线一览表P113-115

#### 3.5.4 空方尖兵
- **定义与特征**：下跌途中，一根带长下影的K线（下跌途中的短暂反弹），之后几根K线反弹整理（不过该阴线开盘价），最后大阴线跌破前低。
- **技术含义**：**看跌信号**。
- **来源**：第一册K线一览表

#### 3.5.5 上升抵抗形
- **定义与特征**：上涨途中连续多根阳线（中间偶有小阴线/十字线），但小阴线收盘价仍高于前一根阳线收盘价（即"跳空高开高走+偶尔跳高收阴"），多方始终抵抗空方打压。
- **技术含义**：**强势看涨信号**。
- **来源**：第一册P90-92

#### 3.5.6 下降抵抗形
- **定义与特征**：下跌途中连续多根阴线（中间偶有小阳线），但小阳线收盘价仍低于前一根阴线收盘价。
- **技术含义**：**强势看跌信号**。
- **来源**：第一册P125-127

### 3.6 缓慢推进/绵绵阴跌类

#### 3.6.1 冉冉上升形
- **定义与特征**：股价经过一段时间横盘后，出现**一连串小阳线**（偶夹小阴/十字），低点高点缓缓上移，呈冉冉升起之势。
- **技术含义**：**看涨信号**（低位出现是大牛股启动前兆）。
- **来源**：第一册P87-89

#### 3.6.2 徐缓上升形
- **定义与特征**：先出现多根小阳线缓缓上升，后拉出中大阳线加速（"小阳铺路+大阳突破"）。
- **技术含义**：**看涨信号**，后市看好。（习题集填空6答案）
- **来源**：第一册P94-96；习题集填空6

#### 3.6.3 稳步上涨形
- **定义与特征**：上涨过程中阳线多、阴线少，阳线实体明显大于阴线，低点高点稳步上移。
- **技术含义**：**看涨信号**。
- **来源**：第一册P92-94

#### 3.6.4 绵绵阴跌形
- **定义与特征**：一连串小阴线（偶夹小阳）缓缓下滑，低点高点逐步下移。
- **技术含义**：**看跌信号**（"绵绵阴跌不止，后市堪忧"，看似不凶实则慢慢熊途）。
- **来源**：第一册P121-123；习题集"K线顺口溜"

#### 3.6.5 徐缓下降形
- **定义与特征**：先出现多根小阴线缓缓下滑，后拉出中大阴线加速下跌。
- **技术含义**：**看跌信号**。
- **来源**：第一册P123-125

#### 3.6.6 下跌不止形
- **定义与特征**：下跌过程中阴线多、阳线少，阴线实体明显大于阳线，持续走低。
- **技术含义**：**看跌信号**。
- **来源**：第一册P125

#### 3.6.7 下探上涨形（深水炸弹/金针探底类）
- **定义与特征**：某根K线大幅低开（甚至跌停），但当天低开高走拉出大阳线，收盘价超过前一天最高价（或开盘价附近）。
- **技术含义**：**强烈看涨信号**（主力洗盘/诱空后拉升），后市常大涨。
- **识别要点/实战注意事项**：
  - 底部穿头破脚+下探上涨形+回踩均线不破 → 积极做多。（第九册No.101）
  - 形态当日常伴巨量。
- **来源**：第一册P134-135；习题集填空3、选择题32；第九册No.101

#### 3.6.8 高开出逃形
- **定义与特征**：大幅跳高开盘（甚至涨停开盘）后一路下行，收大阴线，收盘价低于前一天最低价。
- **技术含义**：**强烈看跌信号**（主力拉高出货），后市常暴跌。
- **识别要点**：常伴巨量；高开出逃+乌云盖顶+穿头破脚等多重信号 → 必跌。（第九册No.102）
- **来源**：第一册P132-134；习题集填空1；第九册No.99、102

### 3.7 多阳线/多阴线组合

#### 3.7.1 低档五阳线
- **定义与特征**：下跌末期低位区连续出现**五根左右小阳线**（可偶夹小阴），低位企稳。
- **技术含义**：**见底信号**（逢低吸纳）。
- **来源**：第一册P79-81

#### 3.7.2 高档五阴线
- **定义与特征**：上涨末期高位区连续出现**五根左右小阴线**，高位滞涨。
- **技术含义**：**见顶信号**。
- **来源**：第一册P139-140

#### 3.7.3 下跌三连阴
- **定义与特征**：连续三根阴线（多为中阴线/大阴线），第三根阴线往往创出新低，跌幅逐日不减。
- **技术含义**：**凶险见顶信号**或加速赶底信号（位置决定）——
  - 高位出现 → 暴跌开始，杀伤力极大
  - 连续大幅下跌后低位出现 → 可能是最后一跌（空方最后宣泄）
- **识别要点**：第七册强调下跌三连阴凶险性；周K线穿头破脚+下跌三连阴+倒T字线 → 后市向坏定局。（第九册No.89）
- **来源**：第一册K线一览表；第七册上；第九册No.89

#### 3.7.4 连续跳空三阴线
- **定义与特征**：连续出现三根带向下跳空缺口的阴线（三连跳空下跌）。
- **技术含义**：**见底信号**（空方力量极度宣泄，"跳三空、气数尽"），可逢低吸纳。
- **来源**：第一册P81-83

#### 3.7.5 连续跳空三阳线
- **定义与特征**：连续三根带向上跳空缺口的阳线（三跳空上涨）。
- **技术含义**：**见顶信号**（三而竭），警惕回调。
- **来源**：第一册P144-146；第九册No.167（跳空三阳线为见顶信号之一）

#### 3.7.6 升势受阻
- **定义与特征**：上涨途中连续三根阳线但阳线实体**逐次变小**，上影线**逐次变长**，显示上攻受阻。
- **技术含义**：**见顶信号**。
- **来源**：第一册P146-148

#### 3.7.7 升势停顿
- **定义与特征**：上涨途中两根大阳线后出现一根**小阳线**（实体明显缩小），上攻节奏突然停顿。
- **技术含义**：**见顶信号**（与尼森停顿形态类似，第一册视角）。
- **来源**：第一册P148-150

#### 3.7.8 阳线跛脚形
- **定义与特征**：连续阳线中某一根阳线收盘未能创新高（或收盘价低于前一根），形成"跛脚"。
- **技术含义**：**见顶信号**。
- **来源**：第一册K线一览表

#### 3.7.9 倒三阳
- **定义与特征**：下跌初期连续出现三根阳线，但三根阳线收盘价**逐次走低**（即高开低走的假阳线），看似红三兵实为庄家拉高出货。
- **技术含义**：**见顶信号/持续下跌信号**（多出现于庄股出货初期）。
- **来源**：第一册K线一览表

#### 3.7.10 下降覆盖线
- **定义与特征**：上涨后，先出现一根穿头破脚形态（大阴线覆盖前阳线），之后再出现一根向下深入的阴线覆盖前面反弹阳线。（习题集填空2答案）
- **技术含义**：**见顶卖出信号**。
- **来源**：第一册P140-141；习题集填空2

#### 3.7.11 低档盘旋形
- **定义与特征**：下跌途中股价经过一轮下跌后进入横盘整理（小阴小阳），之后出现向下跳空大阴线突破盘局。
- **技术含义**：**中继看跌信号**（盘整后继续下跌）。
- **来源**：第一册P120-121

#### 3.7.12 上档盘旋形
- **定义与特征**：上涨途中拉出大阳线后进入高位横盘整理（小阴小阳盘旋），之后大阴线向下突破。
- **技术含义**：**见顶信号/中继整理**（盘旋时间过长→见顶概率大；若放量向上突破则中继）。
- **来源**：第一册K线一览表

#### 3.7.13 加速度线
- **定义与特征**：上涨/下跌末期出现连续跳空大阳/大阴线，K线斜率越来越陡，呈加速度推进状态。
- **技术含义**：**见顶/见底信号**（最后冲刺阶段，物极必反）。
  - 加速上扬 → 见顶信号（第九册No.167）
  - 加速下跌 → 赶底信号
- **来源**：第一册K线一览表；第九册No.167

#### 3.7.14 弧形线（圆弧底/圆弧顶类K线组合）
- **定义与特征**：多根K线慢慢走出弧形（低位弧形为圆弧底、高位弧形为圆弧顶），K线实体渐次变化呈弧形排列。
- **技术含义**：圆弧底看涨；圆弧顶看跌。
- **识别要点**：圆底/圆顶虽被西方技术分析视为技术图形，但第一册K线一览表将其列为K线组合，且尼森书亦有提及塔形类，故保留。
- **来源**：第一册K线一览表P83-84（弧形底）；习题集选择题43圆底

### 3.8 塔形类

#### 3.8.1 塔形底（Tower Bottom）
- **定义与特征**：先出现一根或多根大阴线（左塔柱），随后低位小阴小阳横盘整理（塔底平台），最后一根或多根大阳线拉起（右塔柱），整体形如"塔"。
- **技术含义**：**见底信号**（先暴跌-盘底-暴涨，塔形底构筑完成看涨）。
- **来源**：第一册K线一览表P76-78；尼森1第6章"塔形底部形态"

#### 3.8.2 塔形顶（Tower Top）
- **定义与特征**：先出现大阳线（左塔柱），高位小阴小阳/螺旋桨/十字线横盘（塔顶平台），最后大阴线下跌（右塔柱）。如"门"字形，又称"门字形顶"。
- **技术含义**：**非常凶险的见顶信号**。
- **识别要点/实战注意事项**：
  - 塔形顶横梁由3根螺旋桨构成 → 极其凶险（"塔形顶+螺旋桨=危墙，立即卖出"，第九册No.96）。
  - 门字形顶（左大阳+横梁+右大阴）是主力创新高诱多再反手做空的典型手法，杀伤力极强。（第七册下）
- **来源**：第一册K线一览表P129-130；第七册下；第九册No.96；尼森1第6章"塔形顶部形态"

### 3.9 迭创新高(低)（Eight/Ten New Records，尼森3补充）

- **定义与特征**（尼森3源自酒田战法）：同一方向连续创出8-10个新高（迭创新高）或新低（迭创新低）。

  - 迭创新低：连续8-10根K线创出新低。

- **来源**：尼森3第3章"迭创新高(低)"

## 第四章 K线形态识别通用原则

> 为方便技能识别，整理通用判读原则如下：

### 4.1 位置优先原则
- **位置决定性质**：任何K线形态，首先判断其所处趋势位置（低位/上涨途中/高位/下跌途中/盘整区间）。
- 同一形态在不同位置可能含义完全相反（锤头vs吊颈、倒锤vs射击、T字线、螺旋桨、身怀六甲、红三兵vs前方受阻）。

### 4.2 确认原则
- **反转形态必须等确认**：吊颈线等次日收盘低于实体、倒锤头等次日高开阳线、十字星等第三根K线方向、窗口回补看收盘价而非盘中。
- **量能配合**：关键反转日伴随放量/巨量 → 信号可靠；缩量反转为弱势信号（除涨停/跌停）。
- **多信号共振**：多个看跌/看涨形态同时出现 → 信号叠加可信度陡增（如"乌云盖顶+射击之星+MACD死叉+缺口封闭"几乎必跌）。

### 4.3 实体与影线判定原则
- **实体大小**：长白/长黑实体代表压倒性力量；小实体代表犹豫/平衡。
- **影线长度**：长影线代表"被打回"的失败试探，影线越长信号越明确。
- **大阳线/大阴线量化**：中小盘股≥8%、大盘股≥6%、大盘指数≥4%；但遵循相对原则，接近即认定。
- **非标准图形识别**："基本像谁归谁"原则（第九册No.22）。

### 4.4 时间周期原则
- 信号强度：月K线 > 周K线 > 日K线 > 分时K线。
- 周/月K线出现见顶/见底形态，战略意义远超日K线。
- 高手定性以周/月K线为主，买卖点参考日K线。

### 4.5 窗口（缺口）原则（尼森）
- 窗口构成支撑/阻力；收盘价关闭窗口则原趋势结束；三窗口（三空）后警惕物极必反，等收盘价回补最后窗口才确认反转；三个交易时段不关闭窗口可确认趋势有效。

### 4.6 合成蜡烛原则（尼森2/3）
- 多根K线可合成为一根"合成蜡烛"观察综合方向：以第一根开盘价为开盘、最后一根收盘价为收盘、期间最高为最高、最低为最低。这有助于识别非标准变化图形。

### 4.7 主力诱多/诱空识别要点
- **高位诱多陷阱**：涨停一字线被打开+巨量、高位大阳线（反弹大阳线）几日内被吞、高位吊颈线+跳空高开+天量、高位T字线/倒T字线、V形顶假突破+穿头破脚+除权天量、门字形/山字形顶。
- **低位诱空陷阱**：连续跌停大阴线+锤头/螺旋桨+放量、弹簧线（跌破支撑迅速弹回）、下探上涨形、低位穿头破脚+早晨之星共振。

## 附录B：常见易错点与识别口诀（来自第九册/习题集实战总结）

1. **阳线阴线判定易错**：不是涨就是阳、跌就是阴——阳线是收盘价>开盘价、阴线是收盘价<开盘价。如高开低走收于前收盘之上仍是阴线；低开高走收于前收盘之下仍是阳线。（第九册No.2）

2. **长上影线K线三型辨认**（第九册No.16）：
   - 长上影+小实体在下端+涨势中 = **射击之星**（见顶）
   - 长上影+小实体在下端+跌势中 = **倒锤头线**（见底）
   - 长上影+无实体 = **长倒T字线**
   - 信号强弱看上影长度+实体颜色：射击之星阴线实体强于阳线；倒锤头线阳线实体强于阴线。

3. **长下影线K线三型辨认**（第九册No.17）：
   - 长下影+小实体在上端+涨势中 = **吊颈线**（见顶）
   - 长下影+小实体在上端+跌势中 = **锤头线**（见底）
   - 长下影+无实体 = **长T字线**
   - 信号强弱：锤头线阳线强；吊颈线阴线强。

4. **同时长上下影+小实体辨认**（第九册No.18）：
   - 小实体（可阴可阳）+ 长上下影 = **螺旋桨**
   - 无实体（开=收）+ 长上下影 = **长十字线**
   - 长十字线颜色（红绿）由收盘价略高于或低于开盘价决定，无实质技术意义。

5. **穿头破脚三要素**（第七册上）：①第二根实体长度；②吞没前K线数量（影线不算）；③出现位置。月K线穿头破脚战略看空。

6. **吊颈线确认铁律**：必须等次日收盘价低于吊颈线实体才能看跌，否则信号可被化解。

7. **周/月K线优先级高于日K线**：日K线骗线多，周K线/月K线出现见顶/见底形态更可靠。高手定性看周月，买卖点看日K。（第九册No.6-8）

8. **高位危险信号组合（需高度警惕）**：
   - 射击之星+放量+整数关口/前期高点 → 主力出货
   - 吊颈线+跳空高开+放量 → 主力拉高出货
   - 长十字线+螺旋桨组合 → 多空激战主力出货
   - 高位大阳线几日内被吞 → 反弹大阳线
   - 穿头破脚+高开出逃形+缺口封闭 → 必跌
   - 黄昏之星+4连阴+MACD死叉 → 见顶
   - 塔形顶+3螺旋桨横梁 → 极度凶险
   - 门字形/山字形/尖顶形 → 复合见顶
   - 连续跳空三阳线+高位长十字+射击之星+向下缺口+双顶颈线击穿 → 见顶（第九册No.167列6大信号）

9. **低位可靠见底信号组合（可积极跟进）**：
   - 跌停大阴线（赶底）+螺旋桨+早晨之星+双螺旋桨+穿头破脚+两个向上跳空缺口+双底颈线突破+温和放量+MACD金叉 → 9大信号共振（第九册No.205）
   - 锤头/倒锤头+放量+次日阳线确认
   - 底部穿头破脚+下探上涨形+均线翘头向上+放量
   - 月K线早晨十字星+阳线放量+下月继续收阳站稳

10. **大阳线识别铁律**：少数原则+相对原则——不要死抠8%的数字，接近即认定；但必须坚持门槛防止把普通阳线错当大阳线。

11. **非标准图形识别原则**："基本像谁归谁"——不要因为影线差一点就把T字线误认成长十字线等，以整体轮廓归类。
