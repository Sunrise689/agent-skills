# 回答质量归因

## 何时使用

- 触发词："为什么这次答偏了""明明有那条记忆却没用上""是不是技能规则冲突了""要不要加质量监测"。
- 适用：单次或一组回答的质量问题定位；跨窗口趋势评估前的口径建设与观测设计。
- 不适用：给回答内容本身打分评审；在没有装配可见性的环境里断言"记忆漏注入"。
- 前置条件：至少能拿到最终输出与基础元数据（模型名、时间、输出形态）；装配层证据可得多少用多少，缺什么必须显式标 unknown。

## 任务目标

对一次失败回答说清三件事：用户真实意图是什么、第一个偏差发生在哪一层、下一步最小验证是什么。输出必须可复核——候选原因 + 信心 + 替代解释，不把猜测写成根因。最小交付包含：失败现象与用户实际意图、首个偏差层及证据、候选原因（可并列）、可见元数据及其缺失项清单、已确认事实 / 尚不能证明的部分 / 下一步。

## 操作步骤

1. **固定观察对象**：记录用户实际请求、期望结果、模型/运行时/模式（cloud/local）、任务时间、当前上下文边界。输入文本有歧义时先给"上下文支持的语义解释"；证据不足就保留歧义或主动澄清，不替用户圆意。
2. **找首个偏差点**，按三层顺序排查：
   - 输入层：语义还原、转写噪声、专名或条件遗漏；
   - 生成层：意图忠实度、相关性、事实与不确定性处理、输出约束遵守；
   - 归因层：模型/路由及可见参数、记忆状态与新鲜度、技能与编排规则。
   把输入噪声、时效、历史约定记成证据字段，不额外堆因果层。
3. **记忆核查四态**：尽量区分 available（存在于库）/ retrieved（被检索）/ selected（被选中）/ included（实际注入上下文）。判定纪律：只凭最终回答没提到某条记忆，不能断定它未加载；已注入也不代表模型使用了。缺装配证据时 memory_recall 只能记 unknown，不能判 0。
4. **规则冲突检查**：列出本次实际生效的约束——ID、来源、类别（事实资料还是格式/语态要求）、作用范围、优先级。只有找到具体冲突证据才归因给某条技能；不因单一坏例普遍推断所有技能。
5. **模型可见度纪律**：云端托管模型——除非运行时确实返回，不声称拿到原始思维链或 logits，只用可控题目、最终输出和元数据比较；本地模型——仅当运行时明确暴露轨迹时查看，且只当诊断线索，不当真实内部过程或事实正确性的证明；基于候选 token 概率的分类链路不等于通用思维链读取器。
6. **量化观测（口径必须扎实）**：
   - 题集：24 道固定题，覆盖语音歧义、直答、长期记忆调用、时效/新鲜度、技能规则冲突、人设与历史约定、多步约束七类；
   - 人工样本：20~30 条统一口径标注，先用于校准评分一致性，再谈趋势；
   - 最小元数据（每条回答一行 JSONL；字段不可见时填 null 并标注来源，不填猜测值）：ts、trace_id；platform/provider/model/model_version/mode；context_tokens（值 + 来源 estimate/usage/unavailable）；input_flags（记标记，不复制敏感原文）；memory_refs（ID + 四态 + as_of）；skills（ID + 版本）；active_constraints（ID + 来源 + 类别 + 作用域）；output_shape；review（分项评分、first_divergence、候选原因 + 信心 + 脱敏证据引用、标注人）；
   - 评分锚点 0~2 分：intent_fit（0 意图误解 / 1 部分还原 / 2 符合真实意图）、relevance（0 没回答 / 1 有关但漏核心 / 2 直接覆盖）、memory_recall（无装配证据记 unknown）、rule_conflict（记录冲突规则来源）、factuality（0 明显错误 / 1 有未证实主张 / 2 有证据或妥善表达不确定）；允许 unknown，不为算平均分强填；
   - 趋势评估：任务分布相近、模型与上下文信息匹配、每窗口样本量充足（建议 50 条以上）才做对照，且必须报告样本量与区间；条件不同或证据不足一律写"信号不确定"。
7. **给最小下一步**：优先本机保存、脱敏、可复核的元数据；观测钩子先 shadow 记录与告警。没有上下文组装/模型请求可见性的钩子不能证明记忆漏注入；主链路自动拦截、删规则或改写答案属于高危动作，须另行明确授权。

## 坑与红线

- 不臆测云端内部推理：看不到就是看不到，只用行为证据说话。
- "回答里没提" ≠ "记忆没注入"；"注入了" ≠ "被使用"。四态没分开，归因即作废。
- 不要为凑平均分强填分数；unknown 是合法值。
- 默认不留原文、凭证、完整思维链或 logits；只存脱敏证据引用，复核原文走本机受控文件并人工脱敏。
- 单例不当趋势：换了模型或换了任务分布的对比，不构成趋势证据。
- 本技能只做回答质量归因，与数值建模是两套证据口径，不要混用。

## 验证方式

- 可复核：第三者凭记录的元数据与证据引用，能复走归因路径并得到同一首个偏差层。
- 口径一致：两名标注人对同 10 条样本的分项评分差异不超过 1 档。
- 边界正确：抽检"记忆未注入"类结论，每条都附四态装配证据，而非仅凭"回答没提"。
