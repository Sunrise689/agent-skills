# 全网API比价助手（API Price Finder）—— 省钱专家，不是全量比价器

一句话需求 → 一份"实际支付成本"视角的候选清单。**核心第一性原理：比价看的是"实际支付成本"，不是挂牌价。** 就像外卖要看领券后的价格，API 要看算上缓存命中、优惠、代金券、教育折扣之后的真实成本。

## 🎯 定位差异化（灵魂）

**我们不是"又一个比价网站"，是"预算敏感开发者的省钱专家"。**

- **不做**全模型比价——Claude/GPT 谁都知道、都知道贵，列它们没意义（有钱人不需要省钱工具，旗舰也不靠比价选择）
- **只做**免费 + 低价赛道——默认范围就是「免费 或 输入价≤$1/M 且综合单价≤便宜锚点（DeepSeek V4 Pro / GPT-5.6 Luna）」
- **核心武器**（竞品都没有）：
  1. **免费光谱5档**——免费不是非黑即白（真无限/有额度/名义免费用不了/免费但旧/促销性），绝不允许只写"免费"
  2. **智力对标锚点**——不列抽象指数，用「≈豆包2024版」让人秒懂
  3. **宝藏渠道**——书生9000万/月、Qwen3-Coder免费版等被低估的省钱源
  4. **套餐绑定陷阱**——小米99元积分不结转、GLM编程套餐自然语言弱，教人避坑
  5. **第三方质量标注**——硅基的DeepSeek≠官方可能降质
- **旗舰模型**：默认不出现（--all 才看），因为它们不解决"省钱"问题

本技能 = **固定公式 + 最新实时数据**：所有人输入一样，只有数据时效在变。不需要用户提供个性化参数，默认值即最优，直接跑。

## 范围限定

**默认只搜 LLM 文本模型**（对话/代码/文档/RAG/推理等文本场景）。图片/视频生成模型不纳入默认搜索。
- 用户明确要图片/视频 API 时：单独按图片/视频维度搜索
- 用户没提时：输出末尾加一句提醒「如需图片/视频生成模型的比价，告诉我一声，我可以帮你搜」

## 核心价值

1. **数据源锁定**：价格+智力指数全部来自 OpenRouter 实时 API（`/api/v1/models` 免鉴权，一拉双得），禁止凭记忆编价格
2. **成本真实换算**：输入/输出/缓存命中按场景算，不是裸单价
3. **场景×智力×价格综合评分**：热门高智力模型（GPT-5.6、DeepSeek V4、Claude、Kimi、GLM）优先，不被冷门低价小模型淹没
4. **DeepSeek V4 Flash 倍数锚定**：每行给出"≈X× DeepSeek Flash"，一眼看出相对基准便宜还是贵
5. **免费光谱打标**：免费分5档，绝不允许只写"免费"二字

## 工作流程

### 第一步：理解需求（10秒）

明确用户的：
- **场景**：编程 / 聊天 / Agent / RAG文档 / 长文档处理 / 推理 / 批处理 / 翻译
- **约束**：预算范围、上下文长度要求、质量底线、是否接受免费（免费要提示质量风险）
- **用量**：有就给，没有不用问——直接按默认参数跑（见第三步）

### 第二步：锁定数据源（关键！不允许随意搜）

**⚠️ 铁律：价格与智力数据必须来自真实数据管道，禁止凭记忆编价格。** 执行顺序：

1. **必须运行 `python main.py`（OpenRouter实时API，免鉴权）**——这是价格+智力数据主干：
   - `python main.py top 10` → 默认：自动场景 + 便宜锚点范围，综合性价比Top（JSON）
   - `python main.py --html top 10` → HTML 可视化表格（浏览器直接打开），含智力指数列/综合单价/DeepSeek Flash倍数列/官方申请链接
   - `python main.py search <关键词>` → 查特定模型（如 deepseek、coding、kimi）
   - `python main.py free` → 免费模型
   - `python main.py compare <id1> <id2>` → 对比
   - `python main.py top 10 --all` → 看全量（含高端旗舰如 Claude Opus）
   - `python main.py --scene coding top 10` → 强制编程场景（全部按 coding_index 排）
   - `python main.py --scene agent --min-intel 40 top 10` → Agent场景 + 智力门槛40
   - 模型ID含 `:free` 后缀的即免费模型
2. **OpenRouter 同源附带 Artificial Analysis 智力指数**：同一份 API 返回里，154 个主流模型带 `benchmarks.artificial_analysis` 字段（`intelligence_index` / `coding_index` / `agentic_index`），热门全覆盖：openai/gpt-5.6-*、deepseek/deepseek-v4-*、anthropic/claude-*、google/gemini-*、moonshotai/kimi-*、z-ai/glm-*、qwen/qwen3.8-max、minimax/minimax-m3、stepfun/step-* 等。无此字段的模型智力指数显示 —，不参与智力排序。
3. **官方定价页**（16家，见 `references/data-sources.md`）——用 fetch_web 读取交叉基准，无API
4. **宝藏渠道**：书生InternLM、Qwen3-Coder、Groq/Cerebras 免费档（见 `references/data-sources.md`）
5. **权威智力数据**：Artificial Analysis Data API、LMArena（OpenRouter 内嵌指数不够用时补充）

> **铁律**：优先用上述锁定数据源。禁止只查一两家就下结论。只有锁定源查不到时，才允许补充搜索并标注"补充搜索"。

### 第二步补充：联网搜索兜底（🔍 必做，不是可选项）

**数据库负责"已知"，联网负责"发现新"。** 对 top 候选模型，必须联网搜索一次，验证是否有**数据库未收录的新渠道/新折扣/新平台**更便宜：

- 搜索词示例：「{模型名} API 价格 2026」「{模型名} 优惠 折扣」「{模型名} 新平台 上线」「DeepSeek 价格 涨价」
- 重点查：新上线的第三方平台、限时促销、官方新活动、礼品卡/充值折扣、新开源模型托管
- 发现更便宜的新渠道 → 标注「联网新发现：XX平台 ¥X（来源链接）」，覆盖数据库结果
- 没发现 → 标注「已联网核实，当前为最优」
- **为什么必做**：新平台/新折扣数据库不可能实时覆盖（如某天突然冒出的新中转站比 OpenRouter 便宜 40%），只靠内置库会漏掉最新最优解
- 搜索来源标注：关键价格结论附来源链接，不编造

### 第三步：成本真实换算 + 综合性价比评分（数学，脚本已内置）

**场景成本参数**（脚本按场景内置，默认值即最优，不引导用户覆盖）：
- chat / agent：输入90% + 输出10% + 缓存命中70%（行业实测：OpenRouter 100万亿token实网输入≈93%、企业混合负载79-90%）
- coding：输入60% + 输出40% + 缓存命中70%

**综合单价公式**（每百万token）：
```
综合单价 = 输入价 × 输入占比 + 输出价 × 输出占比
实际单价 = 综合单价 × (1 - 缓存命中率 × 缓存折扣)
```

**DeepSeek V4 Flash 倍数锚定**：每行给 `综合单价 / DeepSeek V4 Flash 综合单价` → "≈2.1×"（贵）或 "≈0.6×，比DS Flash便宜40%"（便宜），一眼定位贵贱。

**排序逻辑（top 命令，场景综合评分）**：
1. **选指数（按场景）**：
   - `auto`（默认）→ 按模型类型自动选：编程专用模型（id/名含 code/coder/codex，如 Kimi K2.7 Code、Qwen Coder）→ `coding_index`；Agent模型（含 agent/agentic）→ `agentic_index`；综合模型 → `intelligence_index`
   - `--scene coding` → 全部按 `coding_index`（编程场景专用）
   - `--scene agent` → 全部按 `agentic_index`
   - `--scene chat` → 全部按 `intelligence_index`
2. **分档（帕累托思路，防冷门淹没热门）**：先按指数分档——旗舰≥55 / 主流45-55 / 轻量35-45 / 入门<35，保证每个智力档都有推荐，高智力热门模型（GPT-5.6、DeepSeek V4、Claude、Kimi、GLM）天然排在最前
3. **档内按性价比评分降序**：
```
性价比评分 = 智力指数 / (1 + log10(1 + 综合单价$/M))
```
免费模型（单价=0）评分 = 智力指数本身。价格越低+智力越高 → 分越高。

**默认搜索范围（便宜锚点）**：`top` 默认只搜 **免费 或 综合单价 ≤ 便宜锚点** 的模型。便宜锚点 = DeepSeek V4 Pro 与 GPT-5.6 Luna 两者综合单价中较贵者（这俩本身就是"便宜强模型"的标杆）。高端旗舰（Claude Opus 等）默认不占位，想看全量加 `--all` 或用户直接说"看全部"。

**必须考虑**：
- 第三方折扣价 vs 官方价（价差可达30-80%）
- 套餐/积分制：只算"对外提供API中转"的平台 + 公开积分价（如小米Nimo官方按积分、阿里API积分可中转、GLM编程套餐可接第三方）。不公开积分制不算。扣子等本地平台不算
- 代金券/礼品卡/教育优惠：提醒用户存在"更低的实际支付价"（教育优惠GitHub Education/Azure for Students可内置；礼品卡/闲鱼折扣按需搜索引导，标注黑卡风险）

### ⚠️ 套餐/积分制"绑定陷阱"检查（推套餐时必须标注）

遇到套餐/积分制（如小米Nimo 99元/月、MiniMax套餐、GLM编程套餐），必须逐项检查并标注：

1. **锁定限制**：是否只能用它自家模型？能不能调其他模型？（小米Nimo积分只能自家模型）
2. **结转规则**：积分能不能结转到下个月？（不能结转=用不完就浪费）
3. **量够不够**：折算成token量，按用户实际用量判断够不够（Nimo 5-6亿token/月对多数人够用，但标注"量大≠值"）
4. **能力短板**：该套餐覆盖的模型在哪些场景明显弱？
   - 编程强（GLM编程套餐）→ 自然语言/生成可能不行
   - 通用强 → 编程/推理可能弱
   - 没有万能模型，必须按用户主场景判断"值不值"
5. **值不值判断（核心）**：结合用户实际使用场景分布判断：
   - 若70%以上场景落在套餐覆盖模型的能力范围内 → 值
   - 若用户主场景（如编程）正好是套餐模型最弱的能力 → 即使量大也不值，建议按量付费或混用
   - 示例：程序员一半以上token用于编程，买"量大但编程弱"的小米套餐 = 被绑定+用不了+不能退+不结转，四重坑
6. **退出成本**：不续费会怎样？积分作废？已买额度还能用多久？

### 输出时必须标注"场景短板"

每个候选卡片除了推荐场景，必须标注**不擅长的场景**（如"编程强但自然语言弱""长文档强但推理弱"），防止用户盲目按价格选了却在主场景翻车。

### 第四步：免费光谱5档打标（铁律）

**任何免费结论必须标注属于哪一档，绝不允许只写"免费"二字：**

| 档位 | 定义 | 处理 |
|---|---|---|
| ① 真·无限 | 无token限制（如智谱GLM-4-Flash官方称仅30并发） | 标注"真免费"，但注明并发限制 |
| ② 有额度 | 有免费额度（书生9000万/月、百炼100万/90天、DeepSeek体验金） | 标额度+多久用完 |
| ③ 名义免费实际用不了 | NVIDIA NIM（大量用户抱怨调用失败）、Gemini免费层（砍到20req/天）、Cerebras（5RPM） | 标"实际不可用/强限流"，不算真免费 |
| ④ 免费但旧/弱 | GLM-4.7-Flash≈2025年中轻量、SiliconFlow 9B以下 | 标智力锚点，提醒"免费但质量对应X" |
| ⑤ 促销性免费 | Qwen 3.6 Plus Preview、Step 3.5 Flash限免、OpenCode Zen免费期间数据可能被训练 | 标"促销/限时"，提醒数据风险 |

### 第五步：智力对标锚点（让人秒懂）

不列抽象指数，用"对标锚点"表达模型水平——**锚点必须是大众用过的产品/版本**（豆包、元宝、GPT-4、Claude 3.5这类），不是圈内benchmark。

- 优先查 `references/anchor-library.md` 锚点库
- 库里没有的：现场类比 + 标注置信度（"据Artificial Analysis指数推断，置信度中"）
- 脚本输出的 `智力指数/编程指数/Agent指数` 三个数值直接引用（如"智力60.9/编程77.4/Agent57.8"），跨模型可横向比

### 第六步：质量与托管标注

- **官方直连**：质量有保障
- **OpenRouter等官方中转**：官方模型+平台抽成，质量保真，可能更便宜（平台补贴）
- **自购GPU部署（硅基流动等）**：⚠️ 新模型未开源时无法同步、可能降质，标注"与官方有差异"
- 免费渠道：标注限流/稳定性/数据风险

### 第七步：输出候选清单（格式）

- **默认输出 HTML 可视化表格**：运行 `python main.py --html top 10` 生成单文件 HTML 表格，浏览器直接打开，列含模型ID/名称/上下文/输入价/输出价/缓存价/**综合单价**/**DS Flash倍数**/**智力指数/编程指数/Agent指数**/性价比评分/档位·排序依据/免费档位/官方申请链接；当前按哪个指数排序在顶部与列头标注（active高亮）；顶部附「最高智力免费模型」「最高智力低价模型」与便宜锚点说明
- 表格中自动附官方 API 申请链接（一键跳转申请页），免费模型绿色高亮

**热门模型必须有**：输出候选清单时，GPT-5.6、DeepSeek V4、Claude Sonnet、Kimi K3/K2.7-Code、GLM 等降价后性价比高的热门模型必须出现在推荐里（评分算法已保证），不允许只推冷门小模型。

同时保留**文字摘要**作为对话内简述，每项 2-3 行：

```
【模型名】平台
- 实际成本：¥X/百万token（按场景换算）| ≈DS Flash的X倍 | 智力指数：智力60.9/编程77.4/Agent57.8 | 智力对标：≈GPT-4级别
- 免费档位：②有额度（9000万/月，够用X天）
- 场景短板：⚠️自然语言弱（编程强但聊天/写作不行）
- 质量：官方直连 | 套餐陷阱：仅自家模型（如适用）
```

**末尾统一提醒**：价格实时变动，以官方当天为准；限时促销价会过期；默认只搜便宜锚点以下，想看全量（含高端旗舰）告诉我即可。

## 场景速查（常见需求直接给结论）

### "我要便宜的长上下文跑代码"
- 编程场景参数（60/40/70）→ 运行 `python main.py --scene coding top 10`：全部按 coding_index 排，编程强的（GPT-5.6 Luna、DeepSeek V4 Flash、GLM-5.2、Kimi K2.7-Code）优先
- 关注：Qwen3-Coder免费版、DeepSeek-Coder（缓存命中¥0.02/M）、Kimi K2.7-Code、GLM编程套餐（可接第三方）

### "我要免费API"
- 必须5档打标，优先推：书生（真·大额度）、智谱Flash（真无限）、OpenRouter :free编程池
- 明确排除：NVIDIA NIM（实际用不了）、Gemini免费层（限流严重）

### "我要最先进的便宜模型"
- 运行 `python main.py top 10`：综合评分同时给智力和价格，热门高智力模型优先
- 编程场景用 `--scene coding`、Agent 场景用 `--scene agent`，脚本自动按对应指数排

### 场景 × 指数速查
| 场景 | 排序指数 | 命令 |
|---|---|---|
| 聊天/通用/推理 | intelligence_index | `top 10`（默认auto，综合模型走智力指数） |
| 编程/代码 | coding_index | `--scene coding top 10` |
| Agent/工具调用 | agentic_index | `--scene agent top 10` |
| 编程专用模型（auto） | 自动识别走 coding_index | `top 10` |
| 只要高智力 | 加门槛 | `--min-intel 60 top 10` |

## 边界情况

- **数据源查不到某模型**：如实标注"该模型在锁定数据源中未收录"，允许一次补充搜索
- **价格矛盾**（官方和第三方冲突）：多源交叉验证，取最新可查证的，标注"价差大，建议实测"
- **用户只要一个答案**：给最优推荐+理由，但保留候选清单供对比
- **涉及付费购买**：只提供信息与建议，不替用户下单
